# 生图提示词与关键帧

关键帧回答“观众在这一刻能看懂什么”。先写清关系，再写风格形容词：“人物在左侧看向右后方货架”比“有电影感”有用得多。

## 先做能说明问题的几张

正式扩展前，先做三四张能把故事连起来的关键帧：问题出现的那一刻、事实的状态、原因、改变之后。它们之间的关系清楚，才值得补其余镜头。涉及动作的镜头再补开始和结束两个状态；中间状态用于说明运动意图，不必每一帧都由图像模型生成。先解决最终可读的状态，再回推需要哪些变化。

## 提示词的可执行结构

按需填写，不适用的项省略：

```text
用途：这个镜头要让观众看懂什么
主体：谁或什么，外观用哪份参考（人物 C01、道具 P01……）
动作或状态：此刻正在做什么，或已经发生了什么
关系：人与物、物与物分别在什么位置，视线看向哪里
环境：必要的空间和少量能识别场景的细节
构图：景别、视角、主次、前后层次、文字留白的位置
媒介外观：从风格文件复制的风格段
光色：主光方向，人物衣色，唯一的强调对象
保持项：必须与前后镜头相同的内容
排除项：容易发生、会影响理解的错误，以及“画面不出现任何文字、编号、标签、条码、标志和屏幕内容”
输出用途：完整底图、透明背景主体，或某一动作状态的关键帧
```

例（虚构）：

```text
用途：让观众看到顾客已经到店，店员还没找到包裹。
主体：顾客 C01（成年，短黑发，藏蓝外套）站在左侧柜台外，手持深灰手机；店员 C02（成年，浅灰工作服）站在柜台内侧。
动作或状态：店员刚查看过右后方货架，轻微停顿，表情克制。
关系：两人隔着柜台相对，视线和柜台关系清楚；货架在右后方，待分拣推车在后区。
构图：中景，两人分居两侧，上方留短标题空间，下缘留字幕空间，手机屏幕留干净区域。
媒介外观：（粘贴风格段）
光色：柔和侧上方光；顾客外套低饱和藏蓝，其余以灰阶呈现；本镜不出现橙色包裹。
排除项：重复肢体、两人脸部相同、柜台穿过身体、夸张争吵；画面不出现任何文字、数字、标志。
输出用途：完整场景底图，后期叠加准确文字。
```

## 比较风格：同一场景，只换风格段

比较几个方向时，共享场景、共同约束和画幅保持不变，每个方向只替换风格段和对应的避免项，差异才能直接看出。风格段由导演方案给出；没有时按风格配方现写，只写媒介、线条、材质、配色、明暗和人物造型，不写具体场景。

## 参考图的用途分开写

参考图可以承担身份、风格、构图、物件或空间五种任务。一张现成镜头同时作为全部参照，生成结果会被它的构图和动作锁住。多参考时逐张写明，例如：

```text
参考 1：顾客 C01 的外观与衣服，不沿用其中背景
参考 2：店员 C02 的外观，不沿用其中机位
参考 3：包裹 P01 的比例和十字胶带形状
参考 4：柜台与货架的空间关系
构图以分镜草图为准，风格以已选关键帧为准
```

几张参考的服装、比例、光线互相冲突时，先处理冲突再提交。接口不支持多图时，固定当前镜头最重要的主体，其余用描述、分层素材或后期合成解决。必须保持的品牌、产品和精确物件，直接用已有素材。

## 构图先留文字区

文字留白在生成前决定：主体区、解释区、字幕区分开，例如“人物在左，右侧留浅色文字区，下缘留字幕区”。手机屏幕、手和物件接触处、对象的识别标记不要落在字幕区。先画满再找地方放字，往往只能缩小字号或挡住重点。

## 常见偏差怎样修

| 画面偏差 | 先判断 | 优先修改 |
|---|---|---|
| 人物越来越像另一个人 | 是否丢了人物参考，或几张参考互相冲突 | 恢复固定参考，简化面部和发型描述 |
| 贯穿对象变成多个或换了形状 | 是否同时写了“许多箱子”和“突出这个箱子” | 写明只有这一个对象是强调色，其他同类中性灰 |
| 画面像宣传海报 | 是否只有主题词，缺少具体关系 | 补人物位置、正在做的动作和看得见的后果 |
| 字幕无处可放 | 是否先画满再考虑文字 | 指定留白位置，减少背景物件或改构图 |
| 素描变成硬切三维块面 | 媒介描述是否混用了两种风格 | 保留一种风格段，删去另一种的材质和高光要求 |
| 流程清楚但图像杂乱 | 是否让图像模型承担了全部图形逻辑 | 保留背景，节点、连接和文字独立绘制 |
| 手与物件的接触关系错 | 动作是否太复杂，接触面是否被遮挡 | 改成动作之前或之后的稳定状态，调整角度 |
| 画面里冒出伪文字、编号 | 构图里有屏幕、面板、包装、标牌 | 加排除项，写“表面干净无印字”，或换构图避开这些区域；仍有字就重做或遮罩去字 |

先修影响理解的一个问题，再决定是否细修。背景里不显眼的纹理，不比人物身份和对象位置更值得花次数。

## 维护参考集合

每采用一张新关键帧，把它加入对应人物、道具或场景的参考集合，标明适用的角度。服装漂移回到人物参考，场景颠倒回到总览图，道具变形回到道具参考；不用已经偏离设定的上一镜作下一镜的唯一依据。参考图、生成请求和分镜用同一套编号，返工时能查到某镜依赖了什么。

# 图片与多参考图

先确定图片承担的解释：主体、关系、步骤、对比，或场景。写明构图与必须保留的特征，避免只有风格形容词。

采用图生路线时，把参考图设计成一帧正在发生的事件：谁在什么环境做什么，动作停在哪里，观众应感到什么。以计划片长检查这张图能否承载接下来几秒的连续动作；5–10 秒通常围绕一个动作和一次反应。保留后续动作所需的手、道具、接触位置与构图余量。情绪来自行为、停顿、视线、环境与声音，减少摆拍和过度渲染。

用于图生视频的主参考帧不默认排成标题、卡片、流程图和长段文字。给模型的动作提示与成片字幕分别编写；字幕和准确文字可在剪辑阶段加入。需要解释精确结构时单独安排证据镜头，与故事现场衔接。

每张参考图记录顺序、角色与要求。例如第一张约束产品外观，第二张约束空间布局；不要把二者解释成两个连续时间点。

参考图也会约束构图和动作范围。仅需外观一致时明确可改变机位与动作；需要自由探索事件时可按已选文生路线生成，无需为每镜补图。用户提供的风格图或连环画先提炼材质、色调、空间和叙事方法，不自动要求所有视频复现同一构图。

准确文字或数字先保留为独立表达要求。使用实际可用排版工具排成 PNG 时保存排版源；普通生图若产生错误文字，应修正实际画面，不只在旁白里掩盖。

新图作为新候选登记，采用关系独立更新。需要被图生视频使用的图必须是实际取得并采用的素材。

审阅原图前另存缩小的 JPEG 预览，保留原始媒体供制作使用。720p 是画幅设计参考，实际返回尺寸仍需探测；预览图不替代原件。

将每镜预览并排检查：画面主体、景别、动作或解释关系是否发生有意义的变化。重复素材有连续叙事理由时保留；不能仅靠不同标题把相同画面当成两个独立表达。

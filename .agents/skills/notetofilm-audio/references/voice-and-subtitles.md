# 声音、读法与实际字幕

当前适配器使用 Edge TTS。默认声音可采用 `zh-CN-XiaoxiaoNeural`，实际可用声音以运行环境和服务结果为准。语速、音高和音量只使用已接入字段。

正式旁白负责可读内容；speech_text 用于必要读法展开。修改读法只影响实际朗读输入，不把正文或标题中的正式词改成音译。

每镜保存真实音频、实际时长、服务边界与可生成字幕。边界缺失时如实说明，不用按字数平均分配伪造逐词时间。

字幕显示内容与实际读音对应。单镜时间从本镜起点计算，整片偏移由合成阶段加入。只改字幕字体或输出形式时可复用音频。

在独立环境安装音频依赖之后仍需要 Edge 在线服务可访问；模块存在不等于在线请求已经成功。

需要代理时，可设置 `NTF_EDGE_PROXY`；该值从运行环境读取，不写进项目音频元数据。连接或证书失败时报告实际错误，由本机网络和可信证书配置解决。

制作前按案例语气选择音色和语速，记录在项目或镜头设置中。独立旁白无需视频人物对口型。取得每镜实际音频后，为动作和消化时间留出余量；超过已定片长时补画面、拆镜或调整节奏，不截断旁白。

服务返回整句边界时可以保持整句时间并做换行；没有逐词边界就不标成逐词精确对齐。音频在镜内延后时，字幕使用同一偏移。底部旁白字幕与画面关键词分别记录；修改字体、位置和字幕样式可复用配音。

## 声音、文字与画面各自的来源

旁白来自正式文案及其 TTS 读法，底部字幕来自对应文案和真实时间信息；标题、标签、箭头和图解由后期独立制作。模型原生人声、环境声和配乐分别记录来源；模型画出的标牌或屏幕字符不当作正式字幕或技术证据。

字数和语速估计只用于设计。取得文件后按以下边界检查：

```text
audio.start_seconds + measured_audio_duration <= scene.duration_seconds
subtitles_offset_seconds + last_subtitle_end <= scene.duration_seconds
```

字幕未显式设置偏移时跟随音频开始时间。时长合格后还要核对事件发生时间与旁白时态。长度不合适时先重剪、拆镜或改稿；必要变速须检查自然度，不能靠循环、长期定格或切掉旁白凑时长。改稿后同步正式 `narration`、实际配音和字幕，避免三份内容各说各话。

成片检查包含试听术语、停顿、截断与底声遮蔽；非空音轨和响度合格不能代替试听。

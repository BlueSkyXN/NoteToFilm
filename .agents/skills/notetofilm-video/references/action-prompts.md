# 动作镜头与运镜写法

导演给出事件变化和自由度后，这里把它写成模型能执行的动作提示。所写内容最终映射到当前路由真实支持的字段；能力不确定时按“没有这项能力”处理。

## 一镜分三种运动

镜头里的变化分为主体动作（放下、转头、走到柜台）、环境运动（背景人物、屏幕光、风）和机位运动（固定、推近、跟随、环绕）。先决定这一镜靠哪一种传递新信息，其余写简单：要看清上架动作，就让人物做一次清楚的放置，背景安静，机位固定；要理解流程，就不必生成视频，交给图解。

一镜一个主要动作。允许自然的准备和收尾，但不把拿起、开箱、找货、递交、转身离开塞进同一个片段；需要的话拆成几镜，在剪辑里接。

## 用三个状态写动作

```text
镜头：s09
目的：观众看见箱子放进了确定的货架位置
参考：人物 C02、箱子 P01、货架 E03（只约束外观与空间）
开始：店员双手托住橙色箱子，站在货架空位前，箱子正面朝镜头
中间：双手把箱子平稳送入空位，箱子不旋转、不开合
结束：箱子稳定停在货架上，店员松手并轻微收回双手，停住
主体运动：一次放置，速度平稳
环境运动：背景安静，其他箱子不动
机位：固定中近景，能看见手、箱子和目标位置
保持：箱子大小、颜色、十字胶带；服装与场景方向
排除：新增人物、复制箱子、机位突然变化、任何文字、编号、条码和屏幕内容
后期：位置标签、字幕
```

这比“人物自然运动，镜头有电影感”更接近可执行的镜头。“自然”“电影感”“丝滑”可以最后补一句，不能代替上面的字段。

## 机位写到终点

运镜写起点、方向、终点和停留，不写“镜头缓慢移动”。常用写法：

| 机位 | 提示词写法 | 何时用 |
|---|---|---|
| 固定 | 固定机位，动作在画内完成 | 看清接触、等待、反应和前后状态 |
| 推近 | 镜头推近到 A，停在 B 和 C 同时可见 | 从环境进入细节，终点有新信息 |
| 拉远 | 从 A 的近景拉远，露出周围的 B | 把个体放回范围 |
| 横摇 | 镜头从 A 向右摇到 B，停住 | 沿视线发现相邻对象 |
| 跟拍 | 跟随 A 从 X 走到 Y，A 在画面中的位置稳定 | 移动路线本身有信息 |
| 升起 | 镜头升起，俯看到三个区域同时在工作 | 换一个高度看清关系 |
| 环绕 | 镜头沿弧线绕到右侧约 30–45 度，停在能看见连接处的位置 | 认识另一面；结构要准时改用稳定的两镜 |
| 手持 | 手持跟拍，轻微可理解的晃动，结果出现时稳住 | 跟随不可预知的行动 |

一镜只要求一种机位运动；同时要求推近、横摇和环绕，模型往往哪一个都做不好。

## 给剪辑留头尾

动作前后各留一小段稳定画面（初次可以试 0.5–1 秒），剪辑才能接旁白、调切点。第一帧就开始大动作、最后一帧动作还没落定的片段很难用。不要为了凑长度大幅慢放带手部动作的片段。

## 首尾帧和尾帧接力

- 首帧、尾帧在人物、服装、道具和空间上要相容。开始帧里的箱子朝前，结束帧却换了颜色或胶带，模型要同时处理动作和物体变化，容易变形。先把两张静图改一致，再生成运动。
- 首尾差异应当是一段连续动作能完成的变化。“手持”到“放上货架”可以；从街道直接到室内货架不是一个动作，拆成两镜。
- 尾帧接力的做法见 [模式与输入](modes.md)。

## 重试时只改一个主要因素

先判断失败在哪一层，每次只改一项，保留可用的版本，才知道是哪项修改起了作用：

| 看到的问题 | 下一次优先改什么 | 可以换用的镜头 |
|---|---|---|
| 物体穿过手或货架 | 缩短位移，露出接触面，简化角度 | 物体已经放稳，人物手退出 |
| 人脸和服装变化 | 减少转头与遮挡，恢复人物参考 | 手与物件的局部特写 |
| 两个人的动作互相干扰 | 每镜只让一个人做主要动作 | 一人反应、一人操作，分成两镜 |
| 机位突然飘动 | 删掉多余的运动要求，写明固定视角 | 静态关键帧加后期小幅裁切 |
| 图标和文字变形 | 从生成片段中移除文字和图形逻辑 | 底图加独立标签和路径 |
| 整段没有可用的结尾 | 写明完成动作后稳定停留 | 动作片段接一张结束关键帧 |
| 画面里冒出端口编号、条码 | 构图避开面板标注区、包装和屏幕，或用更浅的景深 | 固定镜头局部模糊；运动镜头重做 |

连续几次卡在同一个动作，换一种镜头表达通常比继续加提示词有效：选动作之前或之后的稳定瞬间，让动作发生在画面边缘只留结果，或者用两镜加一个特写交代。

## 镜头覆盖

一个段落要哪些镜头，用六类视点查漏：在哪里（空间与相对位置）、谁在做（人物状态与站位）、做什么（一个完整小动作的起势、接触、完成）、关系是什么（人与物、物与物、视线）、关键细节（一个标记、一个接口）、造成什么（结果状态、反应、后续动作）。按导演方案只补缺的那一类，不为凑景别多生成。

## 交给合成

每个采用的片段写明：镜头 ID、可用的原片时间范围、需要叠加的文字、与前后镜头相接的位置、仍应保持的对象。例如“开始持箱到放稳后停留可用；货架号与标签另加；下一镜的通知里出现同一个货架位置”。选片与验收见 [选片与动作验收](footage-review.md)。

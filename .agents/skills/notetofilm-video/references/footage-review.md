# 选片与动作验收

保留模型原片，以素材 ID 和原片时间范围记录采用段。请求时长、实测文件时长、最终使用时长分别保存；返回整条文件不等于整条都值得采用。

先用 `ntf inspect FILE --decode --frames 5 --output DIR --max-width 960` 取得缩小的 JPEG 和媒体规格，再连续播放关键动作与衔接。抽帧能定位问题，无法证明帧间运动稳定。

| 检查对象 | 采用前判断 |
|---|---|
| 事件变化 | 观众能看到这一段要求的状态、行动或结果；只有轻微摇晃却承担复杂事件时需要换片或改设计 |
| 接触与物理关系 | 物体接触、动作和空间关系成立；没有穿模、浮动、突然消失或不合理动作 |
| 对象与状态 | 人物、物件、数量和位置连续；没有状态回退、同物变形或并行关系被画成串行 |
| 运动和剪点 | 运镜有目的，主体保持可读；无无规律抖动，出入画方向与相邻镜头衔接 |
| 生成文字 | 屏幕、设备和标牌上的字符未冒充准确技术数据；错误字符需要裁切、遮盖或替换 |
| 表达程度 | 表情与动作服务事件，避免用重复表演代替需要展示的内容 |

只有前半段有效时采用前半段，不为凑足旁白把错误后半段一起留下。缺口优先用已有有效片段重组、拆镜或改稿；确需补拍时说明缺少哪项事件信息，再生成候选。定格可服务阅读和停顿，连续事件不默认用循环或长定格凑时长。

选片记录可包含：`scene_id`、`asset_id`、原片起止秒、采用理由、舍弃原因、仍需补充的内容。记录属于制作备稿；最终窗口使用合成清单真实支持的 `trim_start` 和 `duration_seconds`。

# 恢复生成任务

提交前准备具体输入；提交返回后立即保存动作、通道和任务 ID。未取得文件前不报告视频完成。

短时等待后未完成，下一次继续 run 同一动作。已返回可下载结果但下载中断时，先恢复下载，不重发生成请求。

原请求超时、是否提交成功无法确定时，记录结果不明。可查询时先查，不能查询时说明哪项尚不确定；不要循环添加 retry 制造重复生成。

配置修改不改变旧任务的查询目标，使用原通道快照恢复。明确重做使用新尝试；得到不同候选时保留旧素材与采用关系。

HTTP 200 只说明接口返回了响应，须继续读任务终态、错误码和结果文件。`OutputVideoSensitiveContentDetected.PolicyViolation` 表示输出阶段被拒绝；响应未指明触发对象时记录原因未知，不推定所有文生不可用、网关故障或失败免费。费用按可取得的用量记录核对。

补拍先写明原片缺口与新的表达方案，在现有次数、费用授权内执行。相同拒绝再次出现或已到约定上限时，停止该方向的新提交，保留成功素材并报告未完成内容；可继续其他已授权片段及剪辑。不批量改词反复碰审核，也不擅自换通道绕过检查。

# 面向视频整理材料

先回答：观众是谁、要理解什么、哪些结论必须讲、需要用什么图解释。把事实、意见、示例和待补充项分开。

来源记录使用稳定 `source_id`、名称、相对路径或原始链接、页码或段落位置。有用原图同时保留文件和位置，文字提取不能代替图中的流程关系。

按用途标明材料：事实证据支撑讲述，外观参考约束人物和设备，风格参考说明审美方法，现成媒体供选择剪辑。同一文件可以有多个用途，须分别写明。连环画或风格例图可以启发视频语言，只有用户要求时才把其构图当成逐帧约束。

编写 materials.md 时采用“主线候选、必讲事实、解释与例子、可用图、具体缺项”结构。只保留此次任务实际相关内容；不要把备稿讨论、工具操作过程和版本演变直接放进正式讲解。

遇到多个数字冲突时列出两处内容与来源，不合并成自己猜测的新数字。只整理资料不必强行决定声音和视频时长。

# 方案与分镜设计

## 选择表达方式

读取材料、制作目标和现有方案。只改一镜或保留原稿时沿用已确定的部分；需要选玩法或调整整体方向时，读 [设计选择图](references/design-map.md)，选叙事方式、制作路线和视觉语言，再只读所选路线。

- 组织主线、章节和事实：读 [讲述结构](references/story-design.md)。
- 调整画风、动作、运镜和转场：读 [视觉语言](references/visual-language.md)。
- 决定文生、外观参考或首尾帧约束：读 [镜头自由度](references/shot-freedom.md)。

方案比较给出差异、推荐理由和最能验证方向的一段。只讨论方案时不要求先配置模型或建立项目；已经要求制作时继续安排所需素材与合成。

## 落成可制作分镜

1. 先列章节目标和叙事变化，再逐镜写明画面、动作或静态阅读、声音、准确文字、参考用途、预计时间和衔接。多章节项目可使用 [设计与音画表模板](assets/design-brief.template.md)，省略与任务无关的栏目。
2. 一个业务段落可以使用多条素材，一次模型生成也可以包含多个镜头。将必需事实与允许模型发挥的部分分开；准确数字和图解保留可核对的排版源。
3. 预计时长用于设计节奏，最终窗口按真实音频和采用的媒体安排。检查相邻画面承担的任务是否有区别，以及状态和因果是否连续。

## 保存和接续

需要落盘或继续项目时再读 [本机入口](references/runtime.md)、[项目格式](references/project-format.md) 和 [命令](references/commands.md)。没有项目时 `ntf init`；按 [分镜示例](references/examples.md) 编写 JSON，用 `ntf storyboard PROJECT --file FILE` 保存正式 `storyboard.json` 和阅读版。叙事和路线选择保留在制作说明或备稿中，不当作新增 CLI 枚举。

修改正文后同步正式主记录。分镜驱动的工作流重新 `ntf plan PROJECT`；独立 `generate` 候选加显式 `compose --manifest` 的路线更新分镜和合成清单，保留已有动作 ID。重排镜头保留固定 ID，展示序号随当前顺序更新。

返回方案或正式分镜的实际位置及下一步制作范围。只要求设计时到设计为止；完整制作继续进入所需媒体阶段。

图片或视频方法不能表达原意时，调整对应分镜或说明具体限制，不删除关键事实换取表面顺畅。

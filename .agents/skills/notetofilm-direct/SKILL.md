# 方案与分镜设计

## 先定方向，写成一页摘要

读取材料、制作目标和现有方案。只改一镜或保留原稿时沿用已确定的部分。需要选玩法或调整整体方向时读 [设计选择图](references/design-map.md)，依次决定：

- **片型**：观众主要在跟随、观察、理解、比较还是感受。读 [片型配方](references/formats.md) 中选中的一两节。
- **制作路线**：画面从哪里来、哪些内容要精确控制。设计选择图里有四条路线，只读所选路线。
- **视觉语言**：画风从 [风格库](references/styles/INDEX.md) 选或自定义；主辅风格、人物道具场景的一致性按 [美术设定](references/art-direction.md)。
- **声音**：四层声音的任务和声音方向，读 [声音设计](references/sound-design.md)。

在[设计备稿](assets/design-brief.template.md)开头写出观众看完要知道什么，挑一件能在画面里证明它的事，由此确定主角、事件次序和声音。管理案例跟着作决定的人，看这个决定调动了谁；维修指导跟着同一件设备，看哪里接触、怎样确认到位。动笔前在备稿里比两三条主线（跟着人、跟着物件、从结果回看等），各写一两行，选一条并写理由。用户要比较方向时，再把候选做成多案交给用户。

人物与管理案例的主角要上屏：同一个可辨认的人物形象从开头出现，作决定、调资源、带团队的时刻都在画面里看到这个人，下一镜接上决定带来的变化。用实拍、绘制还是生成的形象，生成形象能否当作本人，片中是否点名，由用户决定，和用途一起在开工前确认。来不及确认时，先用不模仿本人长相的绘制形象和职务称呼，交付时说明。

摘要还要写对标、主辅风格与辨识信号、开头、记忆点、结尾、声音方向和本片禁止项。没有这些约束时，方案容易落到逐句换图、居中大字、元素同时淡入、每镜缓推、全程铺底音乐这类默认做法。决定怎样接到后果、实物怎样原位转成剖面，可看[因果草图](references/shot-studies.md)。

## 写旁白，设计段落

- 旁白和画面上的字：读 [旁白与画面文字](references/script.md)。
- 主线、章节、事实依据、节奏和时长：读 [讲述结构](references/story-design.md)。
- 段落里怎么看、怎么动、怎么接，按要解决的问题查手法卡：[观察方式](references/techniques/camera.md)、[信息变化](references/techniques/info-motion.md)、[衔接方式](references/techniques/transitions.md)。只读用到的卡，卡号和这一处的目的一起写进段落卡。
- 动作、运镜和转场的总体原则读 [视觉语言](references/visual-language.md)；文生、外观参考还是首尾帧，读 [镜头自由度](references/shot-freedom.md)。
- 写完方案或分镜草稿、看完一版成片后，对照 [常见默认做法与修正](references/pitfalls.md)；返工前先用其中的诊断表判断问题出在哪一层。

## 从便宜到贵

制作首版时按最不确定的地方选用下面的方法。已有材料足以定方向时，直接进入分镜。

1. **结构**　按选中的主线排出事件顺序，让核心事件讲得清。两条主线各有代价时，在备稿里写明取舍。
2. **方向画面**　按选定的方向检查开头、记忆点或结尾。用户希望比较画风时，固定同一段内容；区别在节奏或声音时，用可播放的小样比较。优先复用已有素材，生成样图沿用本次的通道和费用授权。
3. **草图粗剪**：Edge TTS 免费，先给全片配临时旁白，用占位卡、草图、代码动画静帧或已有图片排成完整时间线，合成一版看片长、阅读时间和因果是否连得上。
4. **代表段**　用正式素材做最能暴露问题的一段，先检查动作、声音和衔接，再扩大到全片。

需要用户选择方向或作出新的业务取舍时，给出对应阶段的结果。用户明确委托创意选择时，写下选择和理由继续推进。超出已有的次数、费用或通道授权时先确认。只讨论方案时，可以直接根据材料设计，模型和项目留到制作时配置。

## 落成可制作分镜

1. 先列章节目标和叙事变化。需要连续观看的段落写段落卡：开始、变化、完成三个状态，用到的手法卡，关键变化大约在第几秒。相邻镜头写转场对：贯穿对象、A 结束时的状态、B 从哪里接上。再逐镜写明画面、动作或静态阅读、声音、准确文字、参考用途、预计时间和衔接。模板中与任务无关的栏目可省略。
2. 一个业务段落可以用多条素材，一次模型生成也可以包含多个镜头。把必需事实与允许模型发挥的部分分开；准确数字和图解保留可核对的排版源。
3. 预计时长用于设计节奏，最终窗口按真实音频和采用的媒体安排。检查相邻画面承担的任务是否有区别，状态和因果是否连续。

## 保存和接续

需要落盘或继续项目时再读 [本机入口](references/runtime.md)、[项目格式](references/project-format.md) 和 [命令](references/commands.md)。没有项目时 `ntf init`；按 [分镜示例](references/examples.md) 编写 JSON，用 `ntf storyboard PROJECT --file FILE` 保存正式 `storyboard.json` 和阅读版。片型、路线、手法和风格的选择保留在设计备稿中，不当作新增 CLI 枚举。

修改正文后同步正式主记录。分镜驱动的工作流重新 `ntf plan PROJECT`；独立 `generate` 候选加显式 `compose --manifest` 的路线更新分镜和合成清单，保留已有动作 ID。重排镜头保留固定 ID，展示序号随当前顺序更新。

返回方案或正式分镜的实际位置及下一步制作范围。只要求设计时到设计为止；完整制作继续进入所需媒体阶段。

图片或视频方法不能表达原意时，调整对应分镜或说明具体限制，不删除关键事实换取表面顺畅。

# 证据图解：用准确关系推动理解

适合尺寸、结构、标准、因果、流程或数据差异必须讲准的片段。主画面来自可核对的原始证据或可编辑图解；需要人物和环境时可插入相关情境镜头。

1. 从来源中确定需要解释的关系、比较维度和结论，标出必须准确的数值与文字。
2. 按观众理解顺序安排信息：先给定位，再揭示差异或原因，最后落到判断。每次出现的标注承担一个解释任务。
3. 选择局部放大、高亮、分步展开或前后对照。关系需要运动才能看懂时，再做路径、状态或结构变化。
4. 准确文字保留排版源。图层关键帧、遮罩和路径展开可用 `ntf motion` 生成项目素材，再交合成；需要静态阅读时采用有明确阅读顺序的证据镜头。
5. 根据真实旁白和阅读难度安排时间；技术段结束后回到故事中的选择或结果。

先验证最难解释的一段：观众是否知道在比较什么、变化在哪里、结论由什么支持。满屏同时出现、只换标题或无目的缩放，应改成信息逐步揭示。模型画出的伪文字和虚构读数须处理后才能采用。

执行通常需要 prepare、direct、compose；只有画面确需补充时调用 image 或 video。模型调用次数不作为这条路线的完成标准。

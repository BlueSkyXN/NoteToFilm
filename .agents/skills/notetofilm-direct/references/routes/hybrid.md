# 按章节混合路线

先判断每段承担的任务，再从四条路线中选择。混合不是第五种模型模式，也没有固定的动静比例。

| 段落任务 | 可用画面组织 | 衔接关注点 |
|---|---|---|
| 解释准确关系 | 原始证据、对比或图解 | 保持对象和标注一致，给观众阅读时间 |
| 延续指定外观 | 图片驱动的画面 | 保持需要识别的特征和前后状态 |
| 表现事件变化 | 视频驱动的片段 | 让动作与结果衔接，检查采用范围 |
| 利用已有记录 | 现有媒体剪辑 | 按素材来源和实际内容安排顺序 |

这只是组合示例，按材料选择实际需要的段落。统一少量视觉特征、文字体系和声音基调；现场切到技术解释时允许明确改变表达方式，不必把所有片段做成同一种画面。

章节表记录所选路线及切换理由，逐镜表继续记录具体模式和素材用途。通常先验证最影响整体效果或最难控制的一段，再扩展其他部分。一个路线得到成功片段，不证明另一条路线也已可用。

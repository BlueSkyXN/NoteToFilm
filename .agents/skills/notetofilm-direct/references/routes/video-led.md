# 视频驱动：从事件目标探索镜头

适合希望增加现场感、动作变化或发现意外有效镜头的片段。先固定事实和叙事任务，再让模型选择合适的构图、景别、机位和段内切镜。

1. 按 [开放镜头任务模板](../shot-freedom.md) 写清处境、事件变化、结束状态和审美方向。只加入影响事实、识别或剪辑的硬约束。
2. 在当前通道和费用授权内选择少量代表段，时长遵守实际模型范围。纯文生路线无需先生成参考图；需要保持外观时再选择合适约束。
3. 先看返回素材，记录有效时间范围、事件变化和可用剪点。保留好片段，舍弃错误动作，按具体缺口补充。
4. 根据选片结果调整章节内的分镜拆合，保留原来的事实主线。已有固定旁白时围绕旁白选择素材；旁白可调整时与采用画面共同修订。
5. 用真实声音时长确定最终窗口。多条生成素材可以共同承载一段讲述，不要求一段文案对应一次完整生成。

验收重点是动作可读、状态连续、物理关系和表演程度。运镜丰富但事件不清，或出现技术错误，都不能仅凭“更像电影”采用。准确数字、字幕和说明性文字留在可控制的后期层。

执行通常是 direct → video 候选 → 选片与修订 → audio/compose；已取得的音频可直接复用。返回到自动计划前核对已有候选和采用关系，避免重复提交。

# 现有素材剪辑：用已经发生或已经可用的画面成片

适合已有拍摄、录屏、图表、照片、配音或此前生成的有效素材。先判断素材能讲什么，再决定需要补什么。

1. 登记来源、实际时长、画幅、声音和可用时间范围。区分真实记录、演示画面和生成示意，保留原件。
2. 按事件、证据或章节整理有效片段，寻找动作、对象、视线与声音的衔接。沿用已确定的讲述；只有素材缺口影响理解时才调整或补充。
3. 采访或现场声音按真实内容使用；原声、旁白与底声分别决定保留、替换或混合。画面和旁白时间窗口以实际媒体为准。
4. 对准确文字做独立排版，避免通过裁剪或重排改变证据含义。已有图音和顺序足够时直接进入合成。
5. 把缺口写成具体的事件或解释任务，再决定补拍、生成、图解或删去无依据的推断。

验收重点是素材覆盖、引用含义、事件顺序和声音衔接。重复使用片段时检查对象与事件状态，避免已完成的动作无故重新开始。

执行以 import/select 和 compose 为主。素材完整时无需生成模型；素材不足时只补必要部分。

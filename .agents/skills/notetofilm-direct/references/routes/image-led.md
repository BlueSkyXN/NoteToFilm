# 图片驱动：延续已认可的外观与场景

适合已有连环画、关键画面、人物或设备外观得到认可，需要保持识别度的项目。每张图先确定用途：直接成片、外观参考、空间参考或指定首帧。

1. 逐镜检查图片能否表达叙事任务；相邻图重复而没有连续叙事用途时，合并或调整镜头。
2. 需要动作的段落检查手、道具、接触位置、前后状态和构图余量。参考帧限制动作时，先调整参考用途或补画面。
3. 按 [镜头自由度](../shot-freedom.md) 选择外观参考、首帧或首尾帧。保留的特征明确写出，允许变化的机位和动作也明确写出。
4. 先验证代表动作。图生失败或动作不好时，根据原因选择改图、重设计动作、采用静态证据，或在用户允许的路线内改为文生候选。
5. 用有效动作、静态阅读和必要图解组织节奏；准确配字与字幕独立维护，改字时复用画面。

验收重点是参考图带来的外观一致性、真实动作进展和相邻镜头区别。只有轻微晃动的片段不能替代本来需要表现的事件；也无需把每张图都送进视频模型。

执行按需要进入 image → video → compose；现成合格图片直接导入。审阅前生成缩小 JPEG，原图用于制作。

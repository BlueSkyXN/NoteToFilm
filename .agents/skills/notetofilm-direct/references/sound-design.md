# 声音设计：四层声音与声音方向

声音决定观众在哪里停、哪一下有分量。设计时和画面一起定，写进设计摘要和音画表；具体混音由 compose 按声音后期说明完成。

## 四层声音，四个任务

| 层 | 任务 | 在 NoteToFilm 中从哪里来 |
|---|---|---|
| 旁白与对白 | 说明事实、判断和目的 | Edge TTS 配正式旁白；采访或录音用真实原声 |
| 环境声 | 建立空间，让镜头之间连续 | 模型原声（先实测电平，常常大段静音）、用户录音，或本机生成的房间底噪 |
| 动作与提示音 | 让接触、完成、到达被感到 | 用户提供或有授权的音效；提示音、界面音、转场声可用 `ntf score` 合成 |
| 音乐 | 组织推进、收束和余波 | 用户提供或有授权的音乐；无口播的宣传片、片头、落版和方向小样，可用 `ntf score` 写原创配乐，和画面共用一份时间表；有旁白的讲解片音乐让位，没有合适的就不配 |

四层不一样响。先让旁白在普通音量下清楚，再加环境，再加少量动作声；音乐最后进来，说话时让位。

## 先定声音方向

声音没有方向时会落进默认值：全程同一强度的铺底音乐，每个切点一声“嗖”，每个结论一下撞击，结尾一个钟声。写设计摘要时把声音当作和画面同等的一轴；能从片型和风格推出来的项，写一个词即可。

- **对标**：一种曲风、一部片子的配乐，或者“几乎没有音乐的纪录片现场声”。写学什么（律动、配器、空间、结构），不学什么（旋律、采样）。
- **音乐的角色**：推动、托底，或几乎不出现、让环境和动作声说话。讲解片的机制段通常收敛，结果出来后再温和展开。
- **曲线**：整片一条，或每段一条，标出重点时刻。
  - 吸气 → 爆发：铺垫、停顿、重音。用于宣传和片头；重音前真的空一下，空完后的第一个声音是全片最重要的声音之一。
  - 累加：一层一层加，高潮是“全部都在”。用于生长、从零到一、系统形成。
  - 抽空：满编突然只剩一种声音。用于反差、“只需要这一个”，抽空那一刻就是记忆点。
  - 波浪：几次起伏，没有单一高潮。用于氛围和循环。
  - 单线条：一种乐器或一种声音贯穿，留白多于音符。用于极简、诗意。
  - 现场声主导：几乎没有音乐。用于观察、手作、操作。
  - 由满到空：开场最满，越来越少，最后一个声音最干净。用于落在一句话上的结尾。
- **母题**（可选）：一个两三音的提示音或一种材质声，首尾各出现一次，第二次带着新含义。例如开头和结尾用同一个通知音，语义已经变了。

同一工作目录里有之前做过的片子时，看一眼它们的声音方向；除非用户要求系列统一，这一支至少换掉音乐角色、曲线或配器中的两项。

## 轻重靠安排

给一句话分量，可以减少鼓点、让音乐退出、只留环境声，或者等一个小动作完成后再进下一句。观众在读图、看动作结果时，旁白可以留白。关键句前后不堆音效。音乐的变化不一定换曲子：减一层、降低音量、只留一层持续音、短暂退出都行。

## 音效要有物理或信息原因

通知音表示消息到达，扫描声确认扫描动作，纸箱轻响说明放稳了。每个文字出现都配一下，轻重就没了；只给最重要的一两个时刻配重音。音效的材质对上画面的材质（纸、木、金属、玻璃），时间对准动作发生的那一帧。

## 声音会改变事实理解

警报、撞击、人群声会把普通现场暗示成事故；后配的动作声可以服务示意，不能冒充原始现场录音；不同地点用同一条环境声，会被听成同一个现场。采访删节要忠于原意。

## 跨镜的声音

- **声音先行**（J-cut）：下一场的声音先进来，画面稍后切过去，用来把观众引向将要出现的空间或人。
- **声音延续**（L-cut）：画面已经换了，上一场的话还在说完，用来让讲述延伸到相关细节。
- **声音桥**：同一场地的几个镜头共用一条连续环境声；换场地时环境声交替；重要转折也可以故意断开。

提前或延后多少按语义试，不固定成某个秒数。两段关键讲话不同时开始。实现方式见 [衔接方式](techniques/transitions.md) 的 T06–T08。

## 声音的默认味

| 默认做法 | 听感 | 换成 |
|---|---|---|
| 每个重点都配撞击声 | 冲击贬值，所有片子是同一个“砰” | 只给最重要的一两处；其余用本片材质的声音，或者干脆留白 |
| 每个切点都配“嗖” | 剪辑比内容显眼 | 只在真正的甩镜或穿越上用；其余靠环境声和动作声接 |
| 给镜头运动配声：横移、推近、拉开、穿越各一声气流或刷声 | 一阵阵噪声，听不出对应什么 | 音效只给画面里发出声音的东西（纸落下、盖章、扣笔帽）；镜头运动靠画面本身 |
| 说话时铺着一层长音，只比人声低几 dB | 人声底下一直嗡嗡响，像背景噪声 | 说话时配乐比人声低 15 dB 以上，或者停掉，把音乐留给开头、转折和结尾 |
| 音效落在关键字上 | 那个字被盖住，听不清 | 放在旁白的空当里，压在说话上的音效比人声低 10 dB 以上 |
| 全程一条情绪强烈的音乐，镜头跟着它切 | 讲解没有呼吸，旁白被盖住 | 先定问题、发现、解释、结果的位置，再决定音乐何时推进、何时让位 |
| 落版一个钟声加长尾音 | 所有结尾听起来一样 | 母题的最后一次出现、一个干净的动作声，或直接收住 |
| 片中静音处掉到无声 | 像断线 | 铺一层很轻的连续环境声 |

## 写进备稿

设计摘要写声音方向（对标、音乐角色、曲线和重点时刻、母题）。音画表的声音栏写每段用哪几层、关键音效对准哪个动作、哪里留白。不配音乐时写明“不配音乐”；用代码合成时写明对标、配器和曲线。交付说明里列出各层声音的来源（用户提供、授权素材、代码合成），合成的配乐注明听感是否经人耳确认。

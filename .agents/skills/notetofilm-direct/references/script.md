# 旁白与画面文字

旁白、底部字幕和画面上的字各有任务：旁白讲发生了什么、为什么；字幕帮观众跟上正在说的话；画面上的字留下需要准确阅读或记住的对象、数字和判断。先写旁白，再决定哪些词上屏。

## 先写解释骨架

动笔前用大白话写出五件事，能连成一条线，文案就有了主干：

1. 观众先看见什么异常或处境；
2. 人物或组织想做什么；
3. 卡在哪里；
4. 新的材料让我们发现什么；
5. 怎样回答开头的问题。

每段再写一句内部说明：观众听完这一段，比上一段多知道什么。两段答案相同就合并；后一段直接跳到结论、中间缺环节，就补材料或补一句解释。内部说明留在备稿，不进正文。

## 开头

开头给观众一个明确对象和继续看的理由。几种可选写法（例句为虚构）：

| 写法 | 做法 | 例 |
|---|---|---|
| 具体反差 | 两件本该一致的事并置 | 通知说包裹到了，柜台却找不到 |
| 关键行动 | 从人物正在做的事进入 | 店员沿着货架找了一遍，又回头走向推车 |
| 一个细节 | 放大常被忽略的文字、物件或动作 | 问题藏在手机上这句话里 |
| 结果前置 | 先见结果，再追问形成过程 | 顾客已经到店，包裹还没上架 |
| 关系疑问 | 两个角色对同一件事的理解相遇 | 顾客等的是包裹，店员等的是一个位置 |
| 人物原话 | 用有来源的一句话建立经验 | 只在真实采访或材料里有这句话时使用 |

写两三个候选开头，检查各自许下的承诺：开头问“为什么总是找不到”，正文只解释了一次，就把问题改准。片名、履历和品牌片头不必占开头。

## 让角色带着目标和约束出现

人物故事由目标、可用条件、阻碍和行动构成。双方都在认真做事，矛盾仍然可以成立，不需要另造争吵。把抽象标签写成可见的动作：“店员很着急”改成“他看一眼取件号，转身查货架，又回到推车旁”。这样表情、动作、道具和画面都有落点。

角色不必每镜出现。进入机制解释时可以暂时离开人物，回来时让观众看到这套机制对人的影响。

## 因果写出中间一步

“通知早了，所以取不到”压缩过头。用这句检查：“由于某个条件，人物只能采取某种行动，因此出现某个结果。”每个词组都能回到材料编号或明确的演绎设定。删掉“于是”“因此”后只剩两个不相关的事实，说明还缺关系。

两件事先后发生，不等于前者造成后者。材料只支持一个案例时，交代本片讨论的范围；其他可能原因不属于本片时，一句话带过即可。

## 写成说得出口的话

- 第一遍求意思准确，第二遍出声读（或先配一版 Edge TTS 听），第三遍压缩、调节奏。读到想换气却没有停顿处就拆句；“它”“这个”指代不清就把对象说出来。
- 术语先给情景，再给名称。“手机先通知了，包裹还没上架”在前；“通知与上架状态不同步”这类说法放在后面，或者不用。
- 一句一个意群，句长尽量在 25 字以内，在自然停顿处用逗号、句号。配音后字幕按标点切，没有标点的长句会堆成多行。
- 数字、缩写、英文和人名单独试听，必要时用 `speech_text` 调整读法。配音后按 audio Skill 核对实际字幕，把展开的读法校回正式写法，并在该镜指定校订后的 `subtitles_path`。

## 信息密度

一段承担一个主要判断，细节围绕它。新名词、新人物、一组数字或一次空间转换，都要观众重新建立理解，给它们留时间。观众要看图时，旁白少说新信息；旁白在讲复杂句子时，画面少放竞争元素。粗估时长按约 0.2 秒一字，再加镜头停留，见 [讲述结构](story-design.md) 的时间安排。超出目标先删事实或合并章节，再改句子，不靠加快语速。

## 旁白、字幕和画面上的字怎样分工

- 字幕跟旁白。画面上已经写着同一句话的镜头，关掉该镜字幕。
- 画面上的字只留短语：对象名称、对比标签、关键数字和本段判断，例如“已到站”“未上架”“可取”。为什么，由旁白解释。
- 同一内容不在标题、字幕、旁白里重复三遍。引语标明说话者，数据带单位、范围和来源。
- 一段旁白可以跨几个镜头，一个稳定画面也可以承接两句话。切点按理解的变化安排，不按句号切。

## 结尾

结尾可以回答开头的问题、改变原有判断、回到人物处境，或者说明仍未结束的变化。首尾用同一个对象很有效，第二次出现要带着新的认识。最后一句浓缩全片刚解释过的内容，不突然加入正文没讲过的道理。

## 写完自查

- 只读旁白、不看画面：主要论述能否连贯成立，开头的问题有没有被回答，假设或方案有没有被说成已经取得的效果。
- 每句旁白和屏幕文字能对应到材料的事实编号，或在备稿里标为演绎、示意。画面里看不出的细节不写进旁白。
- 第一人称、演绎与真实原话的区分，按讲述结构中“事实与叙述视角”一节处理。

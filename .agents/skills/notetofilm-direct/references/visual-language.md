# 让画风、动作与剪辑共同表达

确定少量可观察的审美特征：色调与材质、空间表现、人物表演程度、画面信息密度。风格参考说明要借鉴的特征，不自动成为视频首帧或逐镜构图。

## 四种运动职责

| 层次 | 表达什么 | 设计方法 |
|---|---|---|
| 事件动作 | 事情如何变化 | 遇到阻碍、采取行动、产生结果；让物件与人的行为可读 |
| 镜头运动 | 观众应该看哪里 | 靠近关键细节、跟随移动对象、揭示空间关系；移动有明确关注目标 |
| 信息动效 | 关系如何被理解 | 高亮、分步展开、前后对照、路径和数量变化；保持标注准确 |
| 转场与剪辑 | 两段内容是什么关系 | 接续动作、同一物件、视线、因果或声音；需要重新定位时直接切换场景 |

事件本身没有变化时，单纯推近图片或晃动镜头很难承载故事。静态证据可以停留供阅读；使用视频表达事件的段落应有观众看得见的进展。

## 按相邻段落设计转场

- 同一对象进入下一阶段：保留辨认特征或接续动作，检查方向、身份和完成状态。
- 现场进入技术解释：从相关细节切入图解，先让观众认出讨论对象，再展开精确信息。
- 原因进入结果：通过动作结果或声音先行承接，避免在画面仍处理中时旁白已经宣布完成。
- 章节或时间发生变化：用明确的新场景、声音停顿或必要标题重新定位；不要求每个剪点加转场特效。

人物表演服务内容。需要对话或情境演绎时明确其性质，不补造真实发言。概念隐喻可帮助理解抽象关系，应保持与事实层的对应，不把夸张画面当作技术证据。

## 落到制作安排

逐镜写清“画面必须发生的变化”和“希望观众注意的位置”，并指定准确文字与声音的来源。生成模型负责它擅长的场景与动作；精确标签、图解和字幕按制作方案由后期处理。

导演要求落到真实工具：视频变速、明确的跨镜转场、配字和音轨使用 compose 清单；图层关键帧、遮罩和路径展开使用 `ntf motion`，生成并采用素材后再合成。字段按 compose 技能说明填写。其他效果先检查已有工具，不把设计要求直接当作已实现参数。

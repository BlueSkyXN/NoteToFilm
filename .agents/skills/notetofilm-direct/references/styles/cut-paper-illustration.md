# 平面拼贴叙事插画（cut-paper-illustration）

> 人物和环境由边缘明确的彩纸色块、角度清楚的平面和适度的重叠拼成，带轻微纸纤维和少量手绘五官；色块既能画人，也能直接变成图解。
> 参照（只学语法）：剪纸拼贴插画、马蒂斯式剪纸构成、当代杂志的平面拼贴人物。不照搬具体作品的人物和构图。

## 本质 / 不是什么

- 本质：**用平面色块组织人物和空间**。每个形状是一张剪下的纸，边缘清楚，叠放有前后；人物仍是成熟的成年比例，五官用少量手绘点出。
- 不是：`editorial-collage` 的照片碎片加胶带拼贴，不是三维纸雕或立体书，不是无脸的企业小人或卡片拼盘。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 剪纸色块 | 衣服、墙面、设备由边缘清楚的色块组成 | 人物、空间 |
| 角度平面 | 形状以斜切的直边为主，少曲线 | 结构、组织 |
| 叠放层次 | 色块互相压住，边缘有极轻的阴影 | 前后关系 |
| 纸纤维 | 色块表面有细微纤维 | 手作、温度 |
| 少量手绘五官 | 眼睛、眉毛用几笔线 | 成年人物、神态 |
| 有限色组 | 深灰、蓝灰、米白加少量赭黄 | 系列视觉 |
| 色块即图解 | 同样的色块排成流程或分组 | 方法形成、协同 |
| 纸片滑入 | 新的形状从画外滑入叠到画面上 | 增补、累积 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里。

## 这个风格最俗的版本

- 画面：高饱和彩纸、圆头无脸小人、满屏卡片、过度复古的纸纹。
- 声音：俏皮的木琴加纸张摩擦声配每个元素。
- 设计备稿写明翻掉了哪几条。可以把重点放在色块从人物到图解的连续上。

## 适配

- 用途：需要鲜明系列面貌的案例；协同、筛选、方法形成的段落；人物场景与结构解释要共用形状语言的片子。
- 内容：组织、流程、团队、服务。
- 不适合：需要照片级证据的段落、精确尺寸的讲解、沉重的悲剧题材。

## 材质与渲染

- 工艺依据：彩纸剪下后叠放、轻压，边缘有一点手剪的不规则和极轻的投影。
- 形状以直边和斜角为主；人物比例、头身比保持成年人。
- 纸纤维很轻；色块之间的投影统一方向。
- 前景、人物和背景都由纸片构成，不混入照片。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 灰蓝米白：深灰 `#3B3F45` / 蓝灰 `#7C8FA0` / 米白 `#EDE6D8` / 赭黄 `#C69A50`。
- 推导：三四种低饱和纸色加一个强调色；图解沿用同样的纸色，强调色只给当前重点。

## 字体

标题用粗壮的无衬线或手剪感的字形，标签用常规无衬线；文字可以排在一张纸片上，像贴上去一样。

## 运动与镜头

- 纸片的运动：滑入、落下、轻微的叠放回弹很小；形状可以平移、旋转、重新组合。
- 镜头语法：固定画面里纸片增补；沿一排色块平移；推近到一块色块，它扩大成下一幅的背景。
- 画面怎么活：一两张纸片的边缘轻轻起伏；其余安静。

## 声音

旁白轻松清楚；音效可以用很轻的纸张声，只在纸片落位时出现；挑配乐时可参考拨弦、木琴或简单的节奏型，讲解段收敛。

## 原生手法

- 色块即图解：人物衣服的色块离开人物，排成流程图的一格，适合从人进入方法。
- 纸片增补：一张一张纸片叠上来，适合清单和累积（M13）。
- 剪开重排：一幅画面沿直边切开，重新排成下一幅，适合结构变化。

## 变化空间

- 结构：一个团队的几种分工；从散落的纸片到一张整齐的表；同一空间重新布置。
- 开场：一张纸片落下；一个人由几块色块拼成；空白纸面上出现第一块颜色。
- 结尾：所有色块排成最终的结构；回到第一幅人物；只留一块强调色。

## 坑

- 纸纹过重，带出旧年代气息：减轻纸纹。
- 场景拆成卡片，人物失去叙事作用：保持完整场景和人物关系。
- 变成无脸企业小人、头小身大：提示词写清成年比例和手绘五官。
- 变成三维纸雕：提示词写“平面拼贴，无透视立体”。
- 生成图出现伪文字：提示词写“不出现任何文字、编号、标志”。

## 风格段

- **风格段**：成熟的二维平面拼贴叙事插画。人物和环境由边缘明确的彩纸色块、角度清楚的平面和适度重叠构成，带轻微纸纤维与少量手绘五官细节。使用正常成年比例、成熟面部和克制神态。深灰、蓝灰、米白与少量赭黄组成统一配色；场景完整连贯。
- **画面中可以观察到**：人物、衣服和墙面由多边形色块组成，纸张拼贴质感明确，蓝灰与土黄色较突出。
- **避免出现**：三维纸雕、玩具模型、无脸企业小人、头小身大、卡片拼盘、过度复古纸纹、任何文字和编号。
- **可调整范围**：纸纹多少、色块大小；保留平面造型与清楚的人物关系。

风格段是起点；换模型或通道后，先用共享场景出一张基准图核对，再批量生成。

## 在 NoteToFilm 中制作

- **路线**：图片驱动的人物场景 + 代码动画的色块图解；两者共用色组。
- **图片生成**：共享场景 + 风格段 + 共同约束 + 避免项；需要单独运动的纸片可用透明背景单独生成。
- **视频生成**：不太适合，纸片质感在生成视频里容易变成三维或糊掉；动作用分层动画代替。
- **`ntf motion`**：纸片层的 `offset` 关键帧做滑入和落位，`reveal` 做剪开。
- **代码动画**：色块即图解、纸片增补、剪开重排；多边形色块和投影都可以直接画。
- **准确文字**：全部后期，可以排在一张纸片上。
- **基准**：开头、记忆点、结尾各一张，检查人物比例、色组和纸纹是否一致。

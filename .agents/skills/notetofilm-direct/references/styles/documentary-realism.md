# 纪实影像（documentary-realism）

> 普通人的真实肤质、棉布和哑光金属，自然光，像在工作中观察到的一个瞬间。分三种变体：自然写实、电影质感、黑白纪实。
> 参照（只学语法）：观察型纪录片、新闻摄影、企业纪实摄影。不照搬具体作品的人物、构图和调色。

## 本质 / 不是什么

- 本质：**观察到的瞬间**。人物和空间清楚、朴实，光线可信，动作正在发生；画面服务“这里发生了什么”。
- 不是：广告片（模特、磨皮、过亮的机房、英雄光），不是强烈的青橙调色，也不是靠去色和颗粒假装“有故事”。

## 三种变体

| 变体 | 特征 | 适合 |
|---|---|---|
| 自然写实 | 柔和中性日光，自然肤色与蓝灰环境，适中的景深和对比 | 交代工作环境、实际处境和人与设备的关系 |
| 电影质感 | 自然窗光形成柔和侧光，前中后景分离，肤色略暖、设备冷灰，细微颗粒 | 第一人称讲述、关键选择、连续的现场叙事 |
| 黑白纪实 | 纯黑白，丰富的中间调，细微颗粒，明亮可读 | 少量回顾、思考或强调人物状态的镜头 |

一支片子选一种为主；黑白通常只作少量段落，不靠去色增加故事。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 真实肤质与年龄痕迹 | 细纹、毛孔、普通发型，不磨皮 | 人物、选择 |
| 材质细节 | 棉布褶皱、哑光金属、纸张边缘 | 工作、物件 |
| 窗光侧光 | 一侧自然光，阴影柔和 | 讲述、思考 |
| 前景遮挡 | 前景有一角设备或物件虚化 | 观察距离、现场感 |
| 手部特写 | 手与工具接触处清楚 | 操作、劳动 |
| 环境声的画面 | 能想象出声音的空间（机房、车间、柜台） | 现场、连续 |
| 细微颗粒 | 很轻的胶片颗粒 | 电影质感、回顾 |
| 中间调黑白 | 黑白里中间灰阶丰富，明亮可读 | 回顾、沉思 |

## 这个风格最俗的版本

- 画面：暗蓝机房、发光屏幕、穿西装的人对着屏幕指点、浅景深糊掉一切、青橙调色。
- 声音：史诗弦乐加心跳声。
- 设计备稿写明翻掉了哪几条。可以把重点放在普通人的动作、日光和一个完整的小动作上。

## 适配

- 用途：现场观察、案例故事的现场段落、人物经历、产品使用场景。
- 内容：真实发生的工作和生活；和图解组合时，影像承担现场、动作和结果，图解承担机理。
- 不适合：需要精确结构、尺寸、内部原理的段落（生成影像的微距看不清毫米级关系）；需要准确文字的屏幕和标牌画面。

## 材质与渲染

- 光线：日光或窗光为主，主光方向写清；不用强烈戏剧光，脸和关键物件明亮可读。
- 景深：适中；需要观察关系时不要过度虚化。
- 色彩：自然写实保持中性；电影质感的冷暖差很小；黑白保留明亮的中间调，不做纪念照或灾难片的气氛。
- 生成画面最容易出现伪文字的地方：屏幕、面板、标签、包装、标牌。构图上避开这些区域，或让它们处在浅景深外。

## 配色与字体

- 配色跟随实景；强调色只出现在后期的标签和字幕上，从美术设定表里取。
- 字体用清楚的无衬线，标签放在留白或半透明面板上，不直接压在人物身上。

## 运动与镜头

- 生成视频最擅长这类画面：真实的小动作、跟拍、推近、手持感。一镜一个主要动作，结果出现时稳住。
- 镜头语法：固定镜头看完一个动作；跟拍陪伴一个过程；推近到手和物件；结束时稳住留出反应。
- 画面怎么活：环境里自然的小动作（风扇、屏幕光、远处走过的人）；不加人为抖动滤镜。

## 声音

现场声和环境声是这种风格的另一半：设备声、脚步、纸张、远处人声。旁白平实；音乐少，能不配就不配。

## 原生手法

- 动作匹配：中景开始的动作在近景完成，适合关键操作。
- 声音先行：下一场的环境声先进来，适合换场。
- 影像进入图解：在影像的尾帧位置画出图解对象，再展开机理。

## 变化空间

- 结构：跟随一个物件从准备到到位；同一现场的前后对比；一天里的几个时刻。
- 开场：一只手的动作；环境声先于画面；一个结果画面。
- 结尾：回到同一位置，状态已经改变；人物离开画面，留下完成的物件。

## 坑

- 生成画面里的伪文字、端口编号、条码：提示词禁止对视频模型常常无效，选片时逐段放大检查；固定镜头可局部模糊，运动镜头重做或换构图。
- 广告模特感、磨皮：提示词写“普通成年人，真实肤质，日常工作服装”。
- 用影像硬讲机理：微距的配合关系交给图解。
- 黑白段太多，全片变沉重：黑白只给少量回顾段落。
- 不同镜头的人物长相、衣服漂移：用参考编号和美术设定表固定。

## 风格段

- **自然写实**：自然纪实摄影风格。普通成年人的真实肤质、细微年龄痕迹、棉布褶皱与哑光金属，柔和中性日光，自然肤色与蓝灰环境，适中的景深和对比度。画面像工作过程中观察到的一个瞬间，人物与空间清楚、朴实。
- **电影质感**：克制的写实电影画面。自然窗光形成柔和侧光与层次分明的阴影，前景、中景和背景清楚分离；肤色自然略暖，设备偏中性冷灰。细微胶片颗粒和柔和高光，适度景深。保持普通成年人的面貌与日常工作状态，画面明亮可读。
- **黑白纪实**：纯黑白的当代纪实摄影。保留真实肤质、年龄痕迹、棉布与金属细节，细微颗粒，丰富中间调和自然窗光。人物与设备通过灰阶层次区分，气氛沉静但明亮可读。
- **避免出现**：广告模特感、磨皮、过亮机房、过度虚化、戏剧化表情、强烈青橙调色、英雄光、棕褐色复古、黑色电影光影、任何可读文字、编号、标志和屏幕内容。
- **可调整范围**：光比、侧光方向、景深、背景清晰度、灰阶对比；保留普通人的形象和可读的脸与关键物件。

风格段是起点；换模型或通道后，先用共享场景出一张基准图核对，再批量生成。

## 在 NoteToFilm 中制作

- **路线**：视频驱动或图片驱动；和证据图解组合时，影像承担现场与结果。
- **图片生成**：共享场景 + 所选变体的风格段 + 共同约束 + 避免项；作首帧时保留后续动作需要的空间。
- **视频生成**：文生或图生都适合；提示词写清一个动作的起止和机位；原生声音先实测电平再决定是否使用。
- **`ntf motion`**：裁切推近、局部去字后的再构图；分层视差用得少，写实画面分层容易穿帮。
- **代码动画**：从影像尾帧进入图解。
- **准确文字**：全部后期。
- **基准**：开头、记忆点、结尾各一张，检查人物是否像普通人、画面里有没有字、光线是否一致。

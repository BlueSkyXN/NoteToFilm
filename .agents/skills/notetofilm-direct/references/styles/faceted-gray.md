# 灰阶棱面叙事插画（faceted-gray）

> 少数几级灰度、清楚的体积转折面，把人物、衣褶和设备概括成利落的块面；人物保持成年比例和克制神态，像一组冷静的新闻插画。
> 参照（只学语法）：新闻与商业媒体解释视频中的灰阶切面人物（例如晚点 LatePost 视频里的人物情境）、单色版画的块面明暗、低多边形插画的体积概括。不照搬具体作品的人物、构图和配色。

## 本质 / 不是什么

- 本质：**用大的明暗切面组织人物和空间**。三到五级灰度，每个面平整、哑光，转折处轮廓利落；体积简化，但年龄、五官比例和神态仍可读。
- 不是：圆润年轻化的三维动画角色（光滑皮肤、成束头发、夸张五官），不是满屏碎三角的低多边形壁纸，也不是写实照片去色。用户说“黑白棱镜”“棱面”“切面人物”时，通常指这一种。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 大切面明暗 | 脸、衬衫、桌面各由三五个明暗面组成，光向统一 | 人物处境、工作关系 |
| 利落轮廓 | 不靠粗描边，靠明暗交界形成清楚的边 | 结构问题、清晰组织 |
| 设备几何化 | 机柜、模块、屏幕被概括成干净的棱柱和平面 | 技术场景、产品 |
| 一处红 | 全画黑白灰，只在关键对象或判断上用一个红色 | 问题、风险、转折 |
| 重点大字 + 字幕分层 | 画面一侧留出空白放两三个字的重点，底部是字幕 | 结论、判断、观点 |
| 剪影化远景 | 背景人物和设备变成一两级灰的剪影 | 规模、群体、环境 |
| 切面重组 | 画面沿切面碎开再拼成下一幅 | 转场、视角变化 |
| 高反差特写 | 只用两三级灰的近景，像版画 | 关键选择、沉默 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里。红色只用在一类含义上（问题、或当前重点），全片保持同义。

## 这个风格最俗的版本

- 画面：满屏碎三角、蓝紫渐变低多边形、玩偶脸、霓虹边光，正中一个人物加大标题。
- 声音：持续的电子铺底加每个切点一下“嗖”。
- 设计备稿写明翻掉了哪几条。可以把重点放在构图、留白、红色只出现一次，或人物神态上。

## 适配

- 用途：解释型案例、管理案例、人物关系与工作组织；作主风格时配浅色或同灰阶的信息图。
- 内容：当代工作场景、技术与组织问题、需要冷静语气的话题。
- 不适合：需要皮肤、布料、毛发质感的情绪近景；需要照片级产品细节的展示；儿童或轻松娱乐题材。

## 材质与渲染

- 工艺依据：像用几块不同灰度的哑光纸或几次套印做出的版画。每个面内部平整，不画渐变和高光。
- 切面的大小服务于识别：脸部切面适中，保留眉眼和年龄线索；头发、衣褶的切面不要太碎；背景切面更大、更简。
- 光向全片统一，主光从一侧斜上方来；暗部不全黑，留一级深灰保留结构。
- 前景主体和背景遵守同一套切面规则，不在棱面插画里贴一张照片。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 中性灰阶：亮 `#EDEDEB` / 中 `#A9A9A6` / 暗 `#4A4A48` / 最暗 `#232322`，强调红 `#B23A2E`。
- 冷灰：亮 `#E9ECEE` / 中 `#9FA7AD` / 暗 `#434B52`，强调红 `#C0412F`。
- 推导：先定四级灰，再给一个强调色；强调色可以从品牌色取，但只用在一类含义上。配套的信息图用同一组灰阶和同一个强调色。

## 字体

重点大字用粗壮的无衬线（思源黑体 Heavy），两三个字，放在画面留白一侧；字幕用常规字重放在底部；人物身份和材料来源用小号字贴近对象。层级是：重点字让观众记住结论，字幕继续解释，身份与来源说明观点归属。

## 运动与镜头

- 一帧之内的出现顺序：人物先可读，身份后出现，观点最后加入。
- 以静为主：切面画面适合固定或缓慢推近；图生视频只做小幅动作，切面在运动中要保持稳定。
- 镜头语法：固定中景交代关系；推近到一个人的脸或一只手表示选择；从人物场景拉开、背景剪影化，表示个人放回群体。
- 画面怎么活：一处红色缓慢变亮；背景剪影里有一两个小动作；其余安静。

## 声音

旁白冷静、清楚；底声用低密度的电子脉冲、稀疏钢琴或安静的环境声。挑配乐时可参考持续低音加少量变化的单线条，转折处抽空。

## 原生手法

- 切面重组转场：上一幅沿切面碎开，碎片落成下一幅的形体，适合视角或段落变化。
- 红色接力：同一个红色从人物场景里的物件转到图解里的节点，再回到结尾。
- 剪影进退：人物从剪影逐渐获得面的层次，适合“这个人是谁”的揭示。
- 留白放字：人物退到一侧，留白里出现两三个字的判断。

## 变化空间

- 结构：同一工作台的前后两种状态；一个人在三个场景里的选择；从个人到组织的尺度变化。
- 开场：高反差的一只手；剪影中的一个红点；一句画面上的判断。
- 结尾：回到第一幅的构图，红色已经消失或换了位置；只留人物和一句话。

## 坑

- 切面过碎，头发和衣褶像碎玻璃：减少切面，扩大明暗块。
- 过度几何化，人物显得坚硬、像机器人：脸部保留成年五官比例和克制神态，切面变化放在衣服和环境上。
- 做成圆润的三维玩偶：提示词排除“光滑皮肤、大眼、圆脸、玩具感”。
- 红色用得太多，失去指向：一个画面最多一处。
- 生成图里出现伪文字和编号：提示词写“画面不出现任何文字、编号、标志”，取回后放大查看机柜和屏幕区域。
- 连续几张灰阶级数和光向不一致：固定一张基准图作风格参考，美术设定表写明几级灰和光从哪边来。

## 风格段

- **风格段**：灰阶棱面叙事插画。以少数明度层次和清楚的体积转折面概括人物、衣褶与设备，轮廓利落，表面哑光，背景更简。正常成年头身比例，保留年龄线索与克制神态。整幅黑白灰，不依赖粗描边。
- **画面中可以观察到**：脸、衬衫和环境由灰阶转折面构成，轮廓较锐，几何概括明显，人物保持成年比例。
- **避免出现**：圆脸大眼、光滑玩偶皮肤、碎三角纹理、纸片边、写实去色照片、任何文字和编号。
- **可调整范围**：头发和衣褶的切面数量、明暗块大小、背景简化程度；保留成年五官比例和克制神态。

风格段是起点；换模型或通道后，先用共享场景出一张基准图核对，再批量生成。

## 在 NoteToFilm 中制作

- **路线**：图片驱动为主；机理用同灰阶的信息图或浅色图解，强调色共用。
- **图片生成**：共享场景 + 风格段 + 共同约束 + 避免项；写清留白一侧给重点大字、底部留字幕区；需要红色时写明“只有某处用一点红色”。
- **视频生成**：图生视频从采用的关键帧开始，动作小、时长短；生成后检查切面是否在运动中闪烁、变成平滑渐变。
- **`ntf motion`**：分层视差、裁切推近；重点大字用 draw 图层的 `text`，配 `fade_in`。
- **代码动画**：切面重组转场、红色接力、同灰阶的流程图；切面用多边形填色，固定种子。
- **准确文字**：全部后期，重点大字、字幕、身份与来源三层分开。
- **基准**：开头、记忆点、结尾各一张，检查切面大小、人物年龄感、红色是否只出现一处。

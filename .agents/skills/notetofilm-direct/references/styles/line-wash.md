# 现代线描淡彩（line-wash）

> 细而自然的石墨、炭笔轮廓，少量轻排线，透明水彩铺一层明亮的颜色；人物、设备和图解可以共用同一种清爽的纸面语言。
> 参照（只学语法）：当代杂志和报告的线描插画、建筑速写淡彩、科普读物插图。不照搬具体作品的人物和构图。

## 本质 / 不是什么

- 本质：**细线定结构，透明色层定气氛**。纸白占大面积，颜色淡而透明，线条保留手绘的自然起落。画面明亮通透，人物仍有成年人的五官和年龄线索。
- 不是：大片空白里放几个孤立小人的课件插画，不是重度复古的水彩，也不是厚涂。和 `graphite-wash` 相比颜色更多、灰调更轻。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 细线轮廓 | 线条细、略有起落，偶尔断开 | 日常场景、工作空间 |
| 透明色层 | 水彩颜色透出纸白，边缘有轻微水痕 | 清爽、明亮的讲述 |
| 线超出色 | 色层没有严格填满轮廓，略有错位 | 手作感、轻松 |
| 明亮纸白 | 大面积纸白，阴影很少 | 浅色系列、与图解共存 |
| 冷灰淡蓝加一点赭黄 | 主色冷，强调处一点暖色 | 技术话题里的人 |
| 局部轻排线 | 只在少数暗部有几道轻排线 | 体积、光向 |
| 线描图解 | 图解和人物用同样的线 | 人物与机理同框 |
| 留白引线 | 细引线从物件指到留白处的标签 | 讲解、标注 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里。

## 这个风格最俗的版本

- 画面：白底上几个小人加大段说明文字，或者泛黄纸面的复古水彩风景。
- 声音：尤克里里或轻快钢琴配全片。
- 设计备稿写明翻掉了哪几条。可以把力气放在人物神态、空间完整和线描图解的衔接上。

## 适配

- 用途：清爽的案例讲述、产品或服务说明、人物场景与技术解释需要共享视觉语言的片子。
- 内容：当代工作和生活场景、流程、服务。
- 不适合：沉重或悬疑的话题、需要强烈明暗的情绪近景、需要照片级证据的段落。

## 材质与渲染

- 工艺依据：先用石墨或炭笔勾出轮廓，再用稀薄的水彩一层层铺色，纸白当作最亮处。
- 线条有主次：人物和关键物件线略重，背景线更轻、更少。
- 颜色透明，不盖住线；面部和设备细节不糊成色团。
- 纸面感很轻，不加做旧和污渍。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 冷灰淡蓝：纸 `#FBFBF8` / 线 `#3A3F45` / 淡蓝 `#B7CAD6` / 冷灰 `#C9CCCC` / 赭黄 `#D2A867`。
- 推导：主色从主题或品牌的冷色里取，强调色用一个低饱和暖色；图解沿用同一组颜色和线宽。

## 字体

标签和标题用细一些的无衬线（思源黑体 Light 或 Regular），或思源宋体；字直接排在纸白处，用细引线连到物件。

## 运动与镜头

- 线描画面适合分层显现：先出线稿，再铺颜色；也可以直接从完整画面开始，推近到细节。
- 镜头语法：固定中景看人与空间；沿纸面平移看一条流程；推近到线描的局部再展开成图解。
- 画面怎么活：一块颜色像刚铺上去一样晕开；引线慢慢画出；其余安静。

## 声音

旁白清楚、轻松但不轻佻；底声用明亮的室内环境声；挑配乐时可参考木吉他、钢琴或马林巴的轻快分解和弦，讲解段收敛。

## 原生手法

- 先线后色：同一画面先出线稿，颜色随讲解铺上，适合“看清了”的时刻。
- 人物线条接图解：人物轮廓延续成流程图的线，适合从现场进入说明。
- 引线标注：细引线从物件伸到留白，标签出现，适合部件讲解。

## 变化空间

- 结构：沿一条服务流程走一遍；同一空间的前后两种用法；一个人和一张图交替出现。
- 开场：只有线稿的场景；一块颜色晕开；一根引线指向一个物件。
- 结尾：线稿全部上色；只留一个上了色的物件；回到第一幅画面。

## 坑

- 孤立小人加大片空白，像课件：保留完整工作空间和人物关系。
- 过度简化，设备细节糊成色团：关键物件的线画清楚。
- 纸纹和做旧太重：用干净的白纸。
- 人物被画成幼态：提示词写清成年比例和年龄线索。
- 生成图里出现伪文字：提示词写“画面不出现任何文字、编号、标志”，取回后放大查看。

## 风格段

- **风格段**：现代线描淡彩叙事插画。细而自然的石墨与炭笔轮廓，少量轻排线，透明水彩色层，明亮纸白、淡蓝和冷灰，少量低饱和赭黄。正常比例的成年人物，五官与年龄线索清楚；设备以同样的细线描绘。保留完整工作空间，画面清爽通透。
- **画面中可以观察到**：细线描与浅色水彩叠加，画面明亮、纸感轻，人物保留较多写实细节。
- **避免出现**：孤立小人、大片空白加说明文字、重度复古纸纹、幼态造型、设备细节糊成色团、任何文字和编号。
- **可调整范围**：面部、衣褶与设备的细碎纹理多少；保留成人形象、完整空间和器件关系。

风格段是起点；换模型或通道后，先用共享场景出一张基准图核对，再批量生成。

## 在 NoteToFilm 中制作

- **路线**：图片驱动为主；图解用代码动画或 `ntf motion` 画同样的线和颜色。
- **图片生成**：共享场景 + 风格段 + 共同约束 + 避免项；写清留白位置。
- **视频生成**：小幅动作的图生视频；线条和水彩边缘可能闪烁，取回后连续看。
- **`ntf motion`**：`reveal` 做先线后色（线稿层和上色层分开生成），`line`/`arrow` 画引线。
- **代码动画**：线描图解、引线标注；线宽和颜色取自美术设定表。
- **准确文字**：全部后期，排在纸白处。
- **基准**：开头、记忆点、结尾各一张，检查人物年龄感、颜色是否透明、图解和插画是否像同一部片子。

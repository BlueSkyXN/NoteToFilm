# 风格库

每个风格一个文件，写这种风格不变的规则：本质、辨识信号、最俗的版本、材质、配色、字体、运动、镜头语法、声音、原生手法、坑，以及在 NoteToFilm 中用生图、视频生成、`ntf motion` 和代码动画分别怎样实现。故事、分镜和时间来自当前材料，不写在风格里。

## 怎么用

- 风格库是起点。三种用法都可以：直接用；以一个风格为底替换其中一两条（例如配色换成品牌色），并在设计备稿里写明改了什么；库里没有合适的，按 [风格配方模板](../../assets/style-recipe.template.md) 现写一份。
- 只读选中的一两个文件。
- 认得出就够：按主题挑两三个辨识信号，至少一个不在「最俗的版本」里。同一风格做第二支片子时换一组信号。文件里的色值是示例，按推导规则从主题和品牌重新配。
- 风格规则与内容分开：换主题时规则保留，结构、镜头、开场和结尾重新设计。

## 没有指定风格时：给三个方向

每个方向配一张基准图或代码动画静帧，让选择有可看的依据。三个方向拉开差距，不只换配色：

- **贴合**：最贴近主题、品牌或已有素材的风格。
- **换语言**：同样的内容换一种画面语言，选自另一种适用路线。
- **大胆**：自定义风格、两种风格混搭，或结构上更大胆的讲法。

比较时保留相同内容和相近场景，差异才能直接看出。

## 混搭

- **一主一辅**：主风格决定全片的配色、字体和运动性格；辅风格只出现在某个段落或签名时刻，例如人物场景用线刻、结构解释用蓝图。
- **按段落切换媒介**：现场、证据和解释可以用不同画面方式，靠同一个贯穿对象、同一套文字体系或同一种转场语法串起来。
- 在设计备稿里写明哪些规则以哪个风格为准；冲突时以主风格为准。

# 排线灰洗纪实插画（graphite-wash）

> 石墨轮廓、局部排线和透明灰洗一起塑形，人物的脸和手画实，背景轻淡，像记者在现场画下的一个瞬间。
> 参照（只学语法）：新闻纪实插画、报告文学插图、商业媒体解释视频里的人物情境（例如晚点 LatePost 的视频）。不照搬具体作品的构图、人物和版式。

## 本质 / 不是什么

- 本质：**用线的疏密和灰洗的面积组织注意**。脸、手和关键物件细节最多，衣服和桌面用大块透明灰洗表现体积，背景只留结构线。观众先看到人的处境，再看到环境。
- 不是：`copperplate-engraving` 的刻线图谱（随形刻线满版、刀线粗细变化），也不是照片加描边滤镜或漫画（粗黑轮廓、平涂）。排线只出现在暗部和需要塑形的地方。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 实脸实手、淡背景 | 细节从人物向外递减，背景只剩几根结构线 | 人物处境、对话、选择 |
| 局部排线 | 暗部有一小片方向一致的排线，其余是灰洗 | 体积、光向、沉思 |
| 大块灰洗 | 衬衫、桌面、墙面是透明灰色水洗面，边缘有轻微水痕 | 日常工作、生活经验 |
| 一处颜色 | 全画黑白灰，只有贯穿对象带一点低饱和颜色 | 追踪一个物件或一个问题 |
| 边缘留白 | 画面四周逐渐淡入纸白，没有硬边框 | 回忆、观察、开场 |
| 起稿线 | 结构辅助线轻轻留在纸上 | 过程、方法、未完成的状态 |
| 手与工具特写 | 手的骨节、指甲和工具接触处画得最实 | 操作、劳动、细节 |
| 线稿退场 | 灰洗退去只剩线稿，线条接到图解 | 从现场进入解释 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选。

## 这个风格最俗的版本

- 画面：满幅均匀排线、发黄做旧纸、人物被画得苍老沉重、正中一个人物肖像。
- 声音：一架钢琴弹单音从头到尾。
- 设计备稿写明翻掉了哪几条。可以用一处颜色贯穿、线稿接图解、明亮纸面建立变化。

## 适配

- 用途：案例故事、人物经历、现场观察；作主风格，配浅色信息图解释机理。
- 内容：当代工作场景、普通人的处境、需要克制语气的管理或社会话题。
- 不适合：要求精确结构和尺寸的讲解（交给图解）、高速卡点、需要照片级产品质感的宣传。

## 材质与渲染

- 工艺依据：先用铅笔起稿，再给暗部加排线，最后用稀释的墨或灰色水彩铺大面。灰洗是透明的，下面的线仍然看得见。
- 细节分布有主次：脸、手、关键物件最实；衣服用两三层灰洗；背景只留轮廓线和极淡的灰。
- 纸面干净、浅色、带很轻的纤维；纸纹不盖住眼睛、手和预留的文字区。
- 前景主体和背景遵守同一套线与灰洗，不在插画里贴一张写实照片。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 中性纸墨：纸 `#F4F3EF` / 墨 `#2B2B2A` / 灰洗 `#9C9C98`。
- 冷灰纸墨：纸 `#F1F3F2` / 墨 `#283038` / 灰洗 `#8E979C`。
- 一处颜色：在上面任一组里给贯穿对象一个低饱和强调色，例如橙 `#C8642E` 或朱红 `#B85D51`。
- 推导：先选能衬清细线的浅纸色，再选足够深的单一墨色；强调色只给一个对象，配套的信息图沿用同一个强调色和纸色。

## 字体

画面上的标签和标题用清楚的无衬线（思源黑体），或与报告文学气质相称的思源宋体；在浅色纸面上直接排，或放在白色小面板上。字号先按手机尺寸定，标签贴近对象，不压在脸和手上。

## 运动与镜头

- 以静为主：图片驱动的镜头靠小幅动作（抬眼、转头、手放下）、裁切推近和 2.5D 分层建立时间，线条和纸纹不闪烁。
- 镜头语法：固定中景看人与人的关系；推近到手和物件看细节；从人物场景拉开、灰洗退去、只留线稿，转入图解。
- 画面怎么活：一小片灰洗像刚铺上去一样慢慢稳定；起稿线在讲“方法”时浮现；其余保持安静。

## 声音

旁白平实、略慢；底声用安静的室内环境声，纸笔、翻页这类轻声只在动作上出现。挑配乐时可参考稀疏的钢琴或弦乐单线条、慢速分解和弦，或者不配音乐，让现场声说话。

## 原生手法

- 线稿到灰洗的“显影”：同一画面从起稿线到完成稿，适合开场或“看清了”的时刻（经典）。
- 灰洗退场、线条接图解：人物场景的轮廓线延续成流程图的线，适合从现场进入机理。
- 一处颜色贯穿：同一个低饱和颜色从插画里的物件延续到图解和结尾。
- 背景淡出为留白：主体保留，四周退成纸白，空出的地方放结论文字。

## 变化空间

- 结构：跟随一个人一天里的几个瞬间；同一张工作台在事件前后的两种状态；一个物件从现场到图解再回现场。
- 开场：手的特写；一张还没画完的线稿；从留白中浮现的人物。
- 结尾：回到同一张台面；只留线稿和一句话；颜色最后一次出现在完成的物件上。

## 坑

- 排线铺满全画，像素描滤镜：只给暗部和关键体积加排线。
- 纸纹和做旧太重，当代案例显得陈旧：用干净的浅纸。
- 人物被画老、画沉重：提示词写清年龄感和“日常工作神态，克制”。
- 生成图里出现可读文字、编号或伪字：提示词写“画面不出现任何文字、编号、标志”，取回后放大查看。
- 连续几张灰度和线密度不一致：固定一张基准图作风格参考，美术设定表写明线与灰洗的比例。
- 图生视频后线条闪烁或糊成灰面（线条类画风的常见风险，本风格未实测）：动作幅度小、时长短、用首帧约束；效果不好就用静图加裁切推近或局部显露。

## 风格段

- **风格段**：成人纪实叙事插画。石墨轮廓、疏密有别的局部排线与透明灰洗共同塑形。人物的脸和手较实，背景较淡；黑、白、中性灰，干净浅纸面。保持日常工作神态与完整场景。
- **画面中可以观察到**：人物用细线、局部排线和灰洗塑形；衣服和桌面以较大的灰色水洗面组织体积，背景较淡，脸和手保留较多细节。
- **避免出现**：满幅均匀排线、照片描边滤镜、复古污纸、过度苍老、粗黑漫画轮廓、任何文字和编号。
- **可调整范围**：灰洗面积、背景线条密度、纸面纹理多少；保留脸、手和关键物件的明确轮廓。

风格段是起点；换模型或通道后，先用共享场景出一张基准图核对，再批量生成。

## 在 NoteToFilm 中制作

- **路线**：图片驱动为主，人物情境用生成图；机理段用浅色信息图（瑞士网格、白板讲解或数据动态的规则，纸色和强调色与插画一致）。
- **图片生成**：共享场景 + 风格段 + 共同约束 + 避免项；构图里写清人物位置和文字留白。需要一处颜色时写明“只有某物件是低饱和橙色，其余黑白灰”。
- **视频生成**：用于少量需要真实动作的镜头，图生视频从采用的关键帧开始，动作小而清楚。
- **`ntf motion`**：分层做 2.5D 视差，`reveal` 做局部显影，`zoom` 加 `focus` 推近到手和物件。
- **代码动画**：线稿接图解的转场；图解用同一纸色、墨色和强调色，线宽接近铅笔线。
- **准确文字**：全部后期；标签放在留白区或白色小面板上。
- **基准**：开头、记忆点、结尾各一张，检查线与灰洗的比例、人物年龄感和颜色是否只出现在一处。

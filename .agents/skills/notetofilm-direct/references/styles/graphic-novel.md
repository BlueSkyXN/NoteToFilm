# 成人图像小说（graphic-novel）

> 清楚而有变化的深色墨线，有限的平涂色块，两三层块面阴影，轻微干笔和纸纹；人物是正常比例的成年人，像一本成熟的图像小说里的一页。
> 参照（只学语法）：欧美与日本的成人图像小说、报道漫画、绘本式新闻插画。不照搬具体作品的人物、分格和配色。

## 本质 / 不是什么

- 本质：**墨线定形，色块定气氛**。轮廓有粗细变化，阴影用两三层边缘清楚的块面，颜色限制在少数几种；人物、设备和背景进入同一种绘画语言。
- 不是：幼态漫画脸、超级英雄漫画（夸张肌肉、速度线、拟声大字），不是照片套绘画滤镜，也不是 `comic-pop` 式的网点与爆炸框。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 变化的墨线 | 轮廓线粗细随结构变化，深蓝黑色 | 人物、动作 |
| 块面阴影 | 两三层边缘清楚的阴影色块 | 体积、光向 |
| 有限色组 | 蓝灰、纸白、一点赭黄 | 系列视觉 |
| 干笔与纸纹 | 色块边缘有轻微干笔，纸面有纹理 | 手作、叙事感 |
| 分格构图 | 一幅画面里分成两三格，表现前后或不同视点 | 连续动作、对照 |
| 近景特写格 | 一格里只有手或眼睛 | 关键选择 |
| 留白对白区 | 预留出对话或旁白的区域（文字后期加） | 人物对话、引语 |
| 剪影前景 | 前景人物剪影框住画面 | 观察、旁观者视角 |

规则：每支挑 2–3 个，至少一个不在下面「最俗的版本」里。

## 这个风格最俗的版本

- 画面：粗黑线、高饱和平涂、对话气泡、速度线、拟声大字，重度做旧纸。
- 声音：节奏强烈的电子乐配每个分格切换。
- 设计备稿写明翻掉了哪几条。可以把重点放在分格节奏、人物神态和有限色组上。

## 适配

- 用途：连续的故事插画、人物经历、需要形成系列视觉的案例。
- 内容：有人物、有处境、有选择的故事。
- 不适合：需要精确数据和结构的段落（交给图解）、需要照片级证据的段落、需要轻松明亮语气的产品片。

## 材质与渲染

- 工艺依据：钢笔或毛笔勾线，平涂底色，再叠两三层阴影色块，最后少量干笔质感。
- 线条主次：外轮廓略粗，内部结构线细；背景线比人物轻。
- 阴影色块边缘清楚，不用柔和渐变；光向全片统一。
- 纸纹很轻，不盖住脸；不做重度做旧。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 蓝灰图像小说：纸 `#F2EFE6` / 墨 `#1F2A36` / 蓝灰 `#6E8496` / 浅灰 `#C8CDD0` / 赭黄 `#C99A4E`。
- 推导：一个主色系（蓝灰或绿灰），一个暖色作强调，墨色比纯黑略带颜色；配套的图解用同一组颜色。

## 字体

旁白和引语可以用有书卷气的字体（思源宋体），标签用无衬线；对话和引语排在预留的留白区，不画气泡尾巴，除非片子明确采用漫画语言。

## 运动与镜头

- 分层制作：前景、人物、背景分开，镜头小幅推移，人物做有限的动作。
- 镜头语法：分格之间的切换就是剪辑；从全景格切到特写格表示注意集中；同一构图两格并列表示前后对照。
- 画面怎么活：背景里的小动作；一格里的色块慢慢加深；其余以静为主。

## 声音

旁白有叙述感、略慢；底声用安静的环境声和少量动作声；挑配乐时可参考弦乐四重奏、钢琴或低调的电子铺底。

## 原生手法

- 分格推进：一幅画面分成几格，依次亮起，适合连续动作或前后对照。
- 格内推近：从一格推进去成为下一幅全屏画面，适合进入细节。
- 色块转场：人物衣服的色块扩展成下一幅的背景色，适合段落切换。

## 变化空间

- 结构：一个人的几个关键时刻；同一场景的几个视点；一页里讲完一段因果。
- 开场：一格近景；一页全景；剪影前景里的观察。
- 结尾：回到第一格的构图；空白格；一个人离开画面。

## 坑

- 纹理和阴影过重，带出复古和沉重：减轻纸纹和阴影面积。
- 幼态、超级英雄化：提示词写清成年比例、克制神态。
- 照片套滤镜：提示词写“二维绘画，墨线与平涂”，排除 photorealistic。
- 线太密太黑：减少内部结构线，拉开主次。
- 生成图出现气泡和伪文字：提示词写“不要对话气泡、不出现任何文字”。

## 风格段

- **风格段**：成熟的二维图像小说风格。清楚而富于变化的深蓝黑墨线，有限的平涂色块，两到三层块面阴影，轻微干笔和纸面纹理。人物为正常比例的成年人，有节制地描绘五官和年龄线索；设备和背景采用一致的绘画语言。蓝灰、纸白与少量赭黄构成画面。
- **画面中可以观察到**：黑色轮廓线、块面阴影和纸面纹理明显；人物、设备与背景进入同一种绘画语言。
- **避免出现**：幼态漫画脸、超级英雄感、密集粗黑线、重度做旧、只给照片套绘画滤镜、对话气泡、任何文字和编号。
- **可调整范围**：纸纹与阴影面积、线条密度；保留轮廓、块面与完整场景。

风格段是起点；换模型或通道后，先用共享场景出一张基准图核对，再批量生成。

## 在 NoteToFilm 中制作

- **路线**：图片驱动；分格版面用代码动画或 `ntf motion` 排。
- **图片生成**：每格单独生成，共用风格参考；写清留白区。
- **视频生成**：小幅动作的图生视频；墨线和色块边缘可能抖动，取回后连续看。
- **`ntf motion`**：分格依次显现（`reveal`），格内推近（`zoom`）。
- **代码动画**：分格版面、色块转场；格线、留白与文字层独立。
- **准确文字**：全部后期，排在留白区。
- **基准**：开头、记忆点、结尾各一张，检查人物比例、线条主次、色组是否一致。

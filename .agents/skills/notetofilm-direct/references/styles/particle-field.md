# 粒子场（particle-field）

> 成千上万个点：从混沌中聚成一个词，沿着看不见的力场流动，在重拍上炸开，再重新组合。
> 参照（只学语法）：数据可视化中的粒子动画、品牌片里的粒子组字、流场艺术。不照搬具体作品。

## 本质 / 不是什么
- 本质：**粒子有目的**：组字、组形、沿场流动、跟随主体；整体像一种物质，而不是到处飞的亮点。
- 不是：通用的「粒子爆炸 + 镜头光晕」模板；也不是没有结构的星空背景。

## 辨识信号：每支片子挑 2–3 个
| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 粒子组字 | 混沌中的点聚成一个词或名称 | 重拍、记忆点 |
| 流场 | 粒子沿看不见的力场流动 | 流动、趋势 |
| 重拍炸开 | 一个点在重拍上炸成粒子 | 冲击、爆发 |
| 尾迹 | 粒子跟着主体拖出轨迹 | 速度、路径 |
| 尘埃和光点 | 慢慢漂浮的颗粒，有景深 | 氛围、宁静 |
| 沙和颗粒 | 粒子像沙一样堆积、塌落 | 时间、侵蚀 |
| 群集 | 粒子像鸟群或鱼群一样聚散 | 群体、协作 |
| 数据粒子 | 一个粒子代表一个单位，按数据聚成形状 | 规模、数量 |
| 流向反转 | 一股点流停住，再整股倒流回去 | 收回、回到本地 |
| 墨点和水彩点 | 粒子是不规则的墨点而不是光点 | 手作、东方 |

规则：
- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 信号从主题里选，不按顺序全上。
- 粒子要有目的：每一次运动都说得出它们要去哪。

## 这个风格最俗的版本
- 画面：黑底上一团发光的粒子炸开、旋转、聚成 logo，四周再加一点镜头光晕。
- 声音：上升的 riser、炸开的 impact、闪烁的 shimmer。
- 设计备稿的视觉语言一栏写明这支片子翻掉了哪几条，或者为什么刻意保留。保留时，把力气花在构图、镜头、节奏或一个意外的记忆点上。

## 适配
- 用途：记忆点、名称演绎、片头、宣传片里的「汇聚」时刻、10–15 秒的预告或竖版短片。
- 内容：AI、数据、网络、社区、品牌、宇宙和自然主题。信息量少，适合一句话，不适合讲功能清单。

## 材质与渲染
- 粒子小（2–5px），大小和亮度有一点随机（固定种子）；10–15% 的粒子用强调色。
- 密度决定形状的可读性：采样步长 5–8px（1080p）；组字用超粗的字，笔画越粗越清楚。
- 可选拖尾：用时间回采（compose 代码动画写法第 13 节），或者 `--subframes 4`。
- 深色背景上粒子用加法混合（`lighter`）会更亮；浅色背景用正常混合。

## 配色
下面的色值是示例，看思路，不要原样照抄。
- 深蓝 `#06101B` / 粒子 `#7DD3FC` / 亮点 `#EAF6FD` / 停顿时的强调 `#FBBF24`
- 白底 `#F7F6F2` / 墨色粒子 `#151515` / 强调 `#FF4A1C`
- 规则：粒子最多两种颜色；强调色的粒子比例固定。颜色变化可以当信号：点流停住的那半拍整股换色。
- 推导：浅底深粒子、深底浅粒子都可以，从品牌来。黑底发光粒子是最常见的那组。

## 字体
组字用超粗的展示字体：Archivo Black、Anton、Unbounded Black；中文用思源黑体 Heavy。

## 运动
- 聚合：弹簧 `{1.5–1.9, 0.72–0.82}`，每个粒子有随机延迟（0–0.9 秒），聚合前带一点噪声漂移。
- 炸开：`outExpo`，0.4–0.8 秒，方向从中心向外加一点随机。
- 流动：粒子位置 = 起点 + 沿流场的解析路径（比如二次曲线或正弦曲线），按周期循环。
- 在一个形状停留足够久让人读清（≥ 1.5 秒），再变成下一个。
- 同一组粒子依次组几个词时，粒子数固定、各词点数不同：按比例取目标点（compose 代码动画写法第 7 节），否则字只组出上半部分。

## 画面怎么活
- 组成一个形状后，粒子不完全静止：每个粒子在目标点附近小幅漂移（2–4px），整体看起来在呼吸。
- 边缘偶尔有几颗粒子脱落飘走，提示这个形状是由粒子聚成的。

## 镜头语法
| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 急推 + 震屏（炸开时） | 冲击 | 重拍 |
| 缓慢拉远，粒子组成更大的形状 | 尺度 | 揭示 |
| 穿过粒子云 | 沉浸 | 转场 |

## 声音
无口播时用 `ntf score`：聚合用 `shimmer` 和上升的 `riser`，炸开用 `impact`，流动用铺底和颗粒感的高频；点流停住时用 `S.gap` 空半拍，倒流的那一下是全片最重的声音。律动可以是四拍底鼓的推进，或三连音琶音压在四拍上；小调、Dorian，或者一个和弦只靠滤波变化；累加（粒子越聚越多，声部越叠越厚）和吸气 → 爆发都合适。

## 原生手法
- 一个点炸成粒子，粒子聚成一个词：适合重拍和记忆点。
- 一个词的粒子流动着重组成另一个词：适合「A 变成 B」，或依次说出“你的模型 / 你的数据 / 你的提示词”这类排比。
- 点流停住再整股倒流：适合“数据不再往外流、回到本机”。比喻要和材料对得上。
- 粒子跟随一个主体形成尾迹：适合速度和路径。

## 变化空间
- 结构：混沌 → 秩序 → 再混沌；一个词变三个词；粒子从画面四角汇聚到中心。
- 开场：一个点；一团漂浮的尘埃；第 0 帧就在流动的点流。
- 结尾：粒子组成名称后静止；粒子散开、只剩一个点（循环）。

## 坑
- 粒子没有目的，就是模板：每次运动都要回答「它们要去哪」。
- 中心留出一个「洞」：炸开的起始距离从 0 开始分布。
- 形状停留太短看不清字。
- 粒子太多、帧时间暴涨：超过 5000 个就换 WebGL。
- 比喻说过头：“数据回家”这类画面会被读成具体的数据流向，只用在材料确实这样写的地方。

## 在 NoteToFilm 中制作

- **路线**：代码动画。
- **图片生成、视频生成**：不用于粒子本身。
- **代码动画**：≤ 5000 个粒子用 Canvas 2D `fillRect`；更多时用 WebGL 点精灵，位置在顶点着色器里由 t 和粒子属性算出。每个粒子的位置是序号和 t 的函数（compose 代码动画写法第 7、8 节），不逐帧积分速度；目标形状在 `READY` 之前于离屏画布采样一次。
- **准确文字**：组成的词和旁边的说明取自材料。

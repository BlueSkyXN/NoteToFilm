# 常见默认做法与修正

没有对标和具体约束时，方案容易落到几种相似的做法。写完方案或分镜草稿、看完一版成片后对照一遍，找出本片实际出现的几条再改。确有理由保留的做法写明理由即可。

## 讲述与分镜

| 容易出现的做法 | 观众看到的结果 | 可以怎么改 |
|---|---|---|
| 只读了用户截取的那一段，用途和观众凭推测 | 片子讲成通用小故事，材料原本要证明的东西没出现 | 先看材料所在文档的目录、评价方式和评语，写进目标卡的“来源语境”；用途靠推测时，设计前请用户确认 |
| 贯穿对象选了物件或技术机理，而材料讲的是人的决定 | 大段时间在解释机理，决定和做法一闪而过 | 物件和机理只交代处境；按材料要证明的内容分配时长，决定的时刻和留下的做法给足时间 |
| 一句旁白配一镜，逐句换图 | 像逐页念材料，画面跟着字走 | 以段落为单位设计观看过程；一段声音可以跨几个视点，切点按理解的变化安排 |
| 第一个想到的结构直接展开 | 同类题材的片子彼此相似 | 先写两三个结构，各两三行（前后对照、跟随一个对象、从结果回看原因等），选一个并写理由 |
| 所有信息在一镜里摆齐 | 不知道先看哪里，结论像展示图 | 分步揭示：先认出对象，再显出差异或原因，最后落到判断 |
| 视觉比喻没对照它会被读成什么事实 | 编排被当成事实：几个入口踩同一拍像在共享同一个会话，账单的合计金额写成 0 像在说完全免费 | 写出每个比喻在观众眼里等于哪句话，和材料对一遍；对不上就换比喻，或在画面上把范围说清 |
| 直接给出结果，缺少前后状态 | 画面“到位”了，却没有变化感 | 写清开始状态、主要变化和完成状态，让观众看到其中的变化 |
| 用更多图片解决“平” | 覆盖更全，观看仍然断续 | 先检查相邻镜头的对象、位置和状态是否接得上，再决定是否补图 |
| 加人物表演制造故事感 | 管理或技术内容被拍成短剧 | 物件、资料、工具和关系也能推进事件；表演按叙事需要安排 |
| 必讲事实全部写进旁白，配音后才看片长 | 实测远超目标，只能整段删改 | 写分镜前按约 0.2 秒/字粗估，超出目标先删事实或合并章节，再改句子 |
| 每一段都用图解页讲 | 成片像讲稿，连续几页文字图表，现场和结果缺席 | 图解只给机理和对比；连续两页图解之后接现场或结果画面，或把相邻两页合并 |

## 画面与运动

| 容易出现的做法 | 观众看到的结果 | 可以怎么改 |
|---|---|---|
| 每镜都加缓慢推近或漂移 | 全片同一种速度，反而更平 | 运动要有关注目标和终点；固定镜头和干净硬切也能有分量 |
| 把克制做成少动、长停 | 全片静止，关键处没有重量 | 克制是选择轻重：变化放在值得理解的位置，关键选择处可以停 |
| 换画风来解决观感问题 | 每轮反馈都推翻美术路线 | 先确认观看方式和段落任务，画风作为表现层调整 |
| 有动作就当作视频段完成 | 动作和事件推进脱节 | 检查动作是否带来状态变化，并与前后镜头相连 |
| 每个剪点都加转场效果 | 转场比内容更显眼 | 先试干净切换；需要转场时按前后两镜的关系成对设计 |
| 居中大字、元素同时淡入 | 与模板片难以区分 | 参照对标作品的构图和节奏，写出本片要避开的几种做法 |

## 文字与声音

| 容易出现的做法 | 观众看到的结果 | 可以怎么改 |
|---|---|---|
| 画面讲不清，靠字幕和旁白解释 | 只看画面看不出发生了什么 | 审看联系表时先不读字幕，判断画面能否看出这一段的变化 |
| 屏幕文字逐字重复旁白 | 阅读和听觉互相抢 | 旁白负责解释，屏幕文字保留需要准确阅读的数字、标签和结论 |
| 采用生成画面里的文字或读数 | 伪文字、端口编号、条码和错误数据进入成片 | 生成时写明画面不出现任何文字，取回后放大检查；准确文字在后期或可编辑的排版源中制作 |
| 给画面加性质角标、图号、修订号或免责小字 | 观众读到“情境演绎”“示意”“图 1”这类与内容无关的字，画面像工作底稿 | 证据、示意和演绎的区分写在备稿与音画表；画面只留字幕和承载内容的准确文字 |
| 把源数据原文直接排进画面（台账、提交记录、日志） | 还没决定能否出现的品牌名、客户名、内部编号跟着进了片子 | 排版前过一遍原文；待定的名称先只用编号或略去 |
| 界面里写命令、参数和终端输出 | 编出来的参数和日志，熟悉的观众一眼认出 | 只写真实存在的命令和参数；输出用色条，或取自真实运行 |
| 旁白写成材料摘要 | 信息过密，听一遍记不住 | 每段只推进一件事；新对象先交代身份，再给名称 |

## 制作与审看

| 容易出现的做法 | 观众看到的结果 | 可以怎么改 |
|---|---|---|
| 方向未定就生成全片素材 | 返工时整批作废 | 先做最能暴露问题的一段，看过结果再扩展 |
| 一直生成素材，始终没有一条能播的版本 | 片长、阅读时间和因果问题到最后才暴露 | 先用临时旁白和占位画面排出整条粗剪，再替换正式素材 |
| 只看规格和解码结果就交付 | 内容问题留给观众发现 | 按时间看全片和剪点，按 compose 交付检查记录看过的范围 |
| 用“更高级”“更有节奏”提修改 | 下一轮不知道改哪里 | 写成具体时点和动作：“s06 通知分支出现后停留太短，延长到能读出通知早于上架” |
| 为了让冻结、黑场报告变干净，加推镜、漂移、光点或改底色 | 报告干净了，画面里的信息没有变化 | 先判断是有意停留还是空等：有意停留在段落卡写明并保留，空等就改那几拍的对象动作或删短 |

## 返工前先判断问题在哪一层

修改从最影响理解的一项开始，修完回看相邻镜头。已经成立的部分保留，不因为一处问题重做全片。

| 看到的问题 | 先检查 | 优先改哪一层 |
|---|---|---|
| 画面漂亮，却不知道在讲什么 | 每镜有没有明确的理解任务 | 文案与分镜；删掉只作装饰的画面 |
| 像幻灯片，像念 PPT | 段落里是不是只有图片替换和标题淡入 | 补开始、变化、结果三个状态；用共享对象连接两镜 |
| 动得多，没意思 | 动作之后有没有新的状态 | 删装饰运动，保住一个完整动作或反应 |
| 太平，没有分量 | 所有镜头是否同尺度、同速度、同一声音强度 | 关键处停住，其余推进；局部与全景形成轻重 |
| 解释像口号 | 标题是否替代了比较过程和产物 | 让字段、对象、依据和结果产生看得见的联系 |
| 越剪越快却越难懂 | 是不是同时要听术语、读字、看动作 | 错开任务，减少重复，保留可读的最终状态 |
| 图像很统一，故事不连 | 是否只统一了画风，没统一对象和时间 | 追踪对象身份、完成阶段和下一镜入口 |
| 转场生硬 | 前后的内容关系或方向、状态断了 | 先改前后素材和切点，再选声音桥或转场效果 |
| 结果看不出来 | 是否只在字幕里宣布完成 | 回到同一对象给出结束状态，或展示真实的产物 |
| 人物、道具每镜都在变 | 参考是否固定，是否沿用了已经偏离的上一镜 | 回到美术设定和参考编号，再修受影响的镜头 |
| 生成视频动作失控、物件变形 | 一镜是否要求多个动作、原图是否支持新视点 | 拆成单个动作，写清首尾状态，或改用切镜和图层 |
| 轻推时细边跳动 | 源图分辨率是否不够，是否整数像素位移 | 提高源图尺寸，用连续坐标，或取消没有价值的微推 |
| 文字压住动作，字幕无处放 | 生图前有没有留文字区 | 重新构图留出解释区和字幕区，不只缩小字号 |
| 刚读完字幕，图已经换了 | 同屏内容和停留是否匹配 | 拆分信息，延长关键的稳定状态 |
| 修改一处导致全片重做 | 人物、文字和背景是否焊在一张图里 | 拆开会变化的层，保留已经有效的素材 |

最后问四件事：观众先看哪里？变化为什么发生？结果是否成立？下一镜接什么？手法卡就是回答这四个问题的工具。同一类问题连续几轮修不掉、两种修法都无效时，回到设计备稿换做法（换技术、换镜头、换结构），或如实说明限制。

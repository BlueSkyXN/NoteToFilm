# 观察方式卡：C01–C14

导演先决定观众怎样观察，再决定摄影机动不动。卡号写进段落卡时，同时写这一处的目的，例如“C04 推近：从工作台进入接口，停在模块前端和面板基准同时可见”。一个镜头通常只用一种主要观察方式。

## 先分清三件事

- **摄影机移动**（推、拉、移、升降、环绕）改变观察位置，前后物体的遮挡和相对大小会变。生成视频能做到，写进提示词。
- **镜头变化**（变焦、移焦）改变视野或清晰平面，观察位置不变。
- **后期画框**（数码放大、平移裁切）只在已有像素里取景，不产生新视点，也看不到原图以外的东西。静图上的 `ntf motion` 推近、平移属于这一类。

三者都能用于强调，但裁切不能承诺“穿过物体”或“看到背面”。分镜里写清用的是哪一种。

## 给运动一个能描述的终点

不写“镜头缓慢移动”，写“从整张工作台推到接口边缘，停住时面板基准和模块前端同时可见”。终点决定需要的清晰度、源图大小和构图余量。运动停住后留出阅读时间，下一镜从这个终点接上。

## 在 NoteToFilm 中怎样做

| 方式 | 适合 | 写法 |
|---|---|---|
| 视频生成 | 真实空间中的推拉、跟拍、环绕、移焦、手持 | 提示词写起点、运动方向、终点和停留；一镜只要求一种机位运动；动作提示的写法见 video 的动作镜头说明 |
| `ntf motion` | 静图和已有视频的数码推近、平移、分层视差 | `zoom_start`/`zoom` 加 `focus`，`crop` 或 `rect` 关键帧，多层 `offset` |
| 代码动画 | 图解里的“镜头” | `motion.js` 的 `camera()`（中心、缩放、旋转），镜头跟随对象的世界坐标 |

数码放大时源图要比成片大；需要放大两倍就生成或准备两倍尺寸的图，否则细线会糊、会抖。

## C01 固定镜头｜让事情自己发生
- **用于**：需要看清接触、等待、反应和前后状态的场面。固定也有调度：主体可以进出画，遮挡可以变化，声音可以引入画外空间。
- **过程**：空位与原样件 → 托盘进入并放稳 → 手退出，新状态留下。观众看见投入与结果。
- **做法**：让主要动作在画内完成；视频提示词写“固定机位”和画内动作的起止，要求背景和物件位置不漂移。需要强调时切一个有理由的近景，不习惯性叠加微推拉。
- **误用**：一张完整静物图停很久，既没有观察价值，也没有开始状态和结果的对照。

## C02 横摇｜沿视线发现
- **用于**：在同一位置跟随左右运动，或从已知主体扫向相邻对象。摄影机旋转，底座基本不动。
- **过程**：人物看向画外 → 镜头沿视线摇过去 → 停在等待中的对象和必要环境上。
- **做法**：先让观众知道为什么转向，到终点及时减速并留出可读状态。视频提示词写“镜头从 A 向右摇到 B，停住”，不同时要求轨道横移。静图模拟要用足够宽的图，只能在画面内移动。
- **误用**：扫过很长的墙或机柜，终点仍没有新对象；把横摇和横移当成同一种空间效果。

## C03 俯仰｜沿垂直关系解释
- **用于**：从手到脸、设备底部到顶部、局部到整体高度。机位不变，朝向上下转。
- **过程**：正在操作的手 → 沿同一物件向上 → 看到操作者对结果的反应。
- **做法**：垂直关系是这一镜存在的理由；可以让动作或声音给出转向提示。稳定的终点比全程匀速扫过重要；终点的头部和结构不要出画。
- **误用**：为了表现“大”一路仰拍，观众不知道为什么要看这个高度。

## C04 推近｜从环境进入细节
- **用于**：逐渐收紧注意，接近需要看清的物件或反应。摄影机真实前进时，透视和遮挡会变。
- **过程**：工作台上的接口 → 靠近接合处 → 模块前端、面板和阻力位置成为重点。
- **做法**：推进距离以终点提供的新理解为准；已经在近景时，直接切细节更明确。视频提示词写“镜头推近到 A，停在 B 同时可见”；静图用 `zoom` 加 `focus`，代码动画把 `camera()` 推到目标对象。
- **误用**：只是放大人脸、没有观看目的；每镜都推，全片同一种速度；低分辨率图推近后细线颤动。

## C05 拉远｜把个体放回范围
- **用于**：从一个物件、人物或局部问题揭示更大的环境、数量、关系或处境。
- **过程**：一个问题样件 → 周围的候选物料和记录进入 → 看见从个案到同类比较的范围。
- **做法**：先让局部有意义，再揭示整体；最初的对象在拉远过程中始终可追踪。静图拉远要求原图本来就有完整的大构图（`zoom_start` 设为大于 1，`zoom` 取负值，结束时回到 1），不靠拉远凭空新增事实。
- **误用**：拉远只露出无关家具；数量变多却没有比较关系，看起来像库存展示。

## C06 横移与跟拍｜陪伴一个过程
- **用于**：移动路线和前后景关系本身有用的场面。横移是摄影机整体左右移动；跟拍是相对主体跟随，可以向前、侧向或在后方。
- **过程**：托盘从备料区出发 → 跟着它穿过一段通道 → 停在现场工作台边。
- **做法**：让对象在画面里的位置相对稳定，环境提供路程线索。视频提示词写起点、终点和跟随对象。路程本身没有信息时，用“离开”和“到达”两镜省略。
- **误用**：绕一圈只是在填时长；拿不同场所的素材伪造同一个连续空间。

## C07 升降与摇臂｜换一个高度理解
- **用于**：改变观察高度，揭示遮挡后的空间层次。和俯仰不同，它改变观察位置。
- **过程**：桌边的单项工作 → 视点上升 → 看见多个同时工作的区域。
- **做法**：终点要让关系更清楚。抽象的并行工作用二维总览（M08）往往比真实空间升降更清楚。视频提示词写“镜头升起，俯看到 A、B、C 三处同时在做”。
- **误用**：抬高就当作“战略视野”，画面里没有新关系；一张平图强行大幅升起，露出拉伸边缘。

## C08 环绕｜认识另一面
- **用于**：需要看侧面、结构或人物之间位置的场面。
- **过程**：正面外形 → 侧面的连接处逐渐显露 → 停在能解释结构的角度。
- **做法**：先定有限的弧段和终点（例如 30–45 度），不直接要求 360 度。人物转身、物体旋转和摄影机环绕是三种不同动作，分别指定。生成视频环绕时，接口、孔位容易随视角变形；结构要求准时，改用两段稳定镜头或可控的三维、图解。
- **误用**：绕一圈又回到原构图；用观察运动掩盖结构问题。

## C09 光学变焦与数字裁切｜改变画面尺度
- **用于**：资料局部、远处观察或快速聚焦。
- **过程**：文件全貌 → 定位一处字段 → 字段足够大，来源身份仍保留。
- **做法**：先确认原图分辨率、关键区坐标和最大可用放大倍数；资料的标题和语境不能被裁到误导。`ntf motion` 用 `crop` 或 `zoom` 关键帧；超出原图能提供的细节时，换素材或重排，不假装有新细节。
- **误用**：每张图都“慢慢放大”；把放大插画当成实拍运镜。

## C10 移焦｜转移清晰重点
- **用于**：同一构图中两个不同距离的对象交接注意。观察位置不变，只移动清晰平面。
- **过程**：前景样件清楚 → 焦点向后转移 → 后景待处理的设备清楚，样件仍可辨认。
- **做法**：先建立两个对象的关系。视频提示词写“焦点从前景 A 转到后景 B”；后期做需要对象分层，在代码动画里对非焦点层加模糊。平图整张模糊再变清楚，不能重建焦平面。看图解或文字时避免持续失焦。
- **误用**：为了“电影感”把关键结构弄糊；焦点切到的对象没有叙事任务。

## C11 手持｜保留身体距离
- **用于**：跟随不可预知的真实行动，或需要身体参与感的场面。
- **过程**：进入拥挤的操作区 → 跟着正在发生的动作重新取景 → 结果出现时稳住或留出反应。
- **做法**：摇晃来自步伐、反应和空间限制；视频提示词写“手持跟拍，轻微、可理解的晃动”，结果出现时写“稳住”。
- **误用**：给图表、文字加抖动；用剧烈晃动假装紧急；晃动让字幕和接触点难读。

## C12 静态图的 2.5D｜有限的空间展开
- **用于**：照片、档案和插画中轻微的前后景视差。它扩展观看方式，不会让平面物体长出背面。
- **过程**：整体插画 → 前景与背景少量相对位移 → 关注对象稳定，空间关系更清楚。
- **做法**：分出前景、主体、背景三层（前景物件可用透明背景生成，或从原图抠出），补齐移开后露出的区域，重要文字单独成层。`ntf motion` 给各层不同幅度的 `offset` 关键帧，近层动得多、远层动得少，幅度先从很小试起。
- **误用**：人物像纸板横滑，胳膊与桌面分离；大幅绕到原图不存在的角度；把分层位移说成真实发生的物件运动。

## C13 甩镜｜快速交接方向
- **用于**：已建立方向的快速注意转移，或风格明确的快节奏段落。
- **过程**：主体发出指向 → 快速横摇形成模糊 → 下一镜沿同一方向接住新主体并稳定。
- **做法**：先确定两镜的内容关系，再用运动模糊藏住接缝；两端方向一致。代码动画按 compose 手法库的甩镜写法，配合 `--subframes`；生成视频写“镜头快速横甩到 B”。最快的那几帧不承担文字阅读。
- **误用**：反向接入导致空间混乱；每镜都甩，观众只觉得忙；用它遮住根本不连续的动作。

## C14 推拉变焦｜异常空间感
- **用于**：明确的主观冲击、失衡或认知突变。主体大小大致不变，背景的尺度关系剧烈变化。
- **过程**：主体稳定在构图中心 → 背景关系明显变化 → 停在主观感受已建立的画面。
- **做法**：需要真实空间或可控三维；单张平图缩放做不出来。生成不稳定时，改用尺度对比和剪辑，不用扭曲变形代替。
- **误用**：日常的管理判断被拍成惊悚；背景“果冻化”被当成正确效果。

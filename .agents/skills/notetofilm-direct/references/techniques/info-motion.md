# 信息变化卡：M01–M16

信息动效让关系发生变化。讲解片里观众要看懂的变化，大多靠这些卡完成：文字和节点什么时候出现，旧信息是保留、退弱还是替换，镜头在图上往哪里走。卡号写进段落卡时，同时写这一处要让观众看懂什么。

## 先写动词，再选效果

“从总览进入某一项”“保留前提再补条件”“把散记录汇成一张表”“让三条线同时可见”都是明确的动效任务；“科技感”“丝滑”“震撼”只能作气质补充。写好动词再选卡。

- **解释对象和视觉对象对齐**：旁白说接口，标注就指向接口；旁白说等级，画面就建立等级这个输出。
- **含义不能被动画偷换**：线条可以代表物流、因果、信息或时间，同一片里要分清；删除表示退出或否定，仍然成立的事实不删；相同尺寸、共同基准和稳定位置帮助比较。
- **视觉出现的先后不等于事实的先后**：并行的工作依次亮起，观众会读成串行步骤。

## 每个变化写三个状态

开始（观众已经知道什么、对象在哪里）→ 中间（哪个动作或新信息改变了局面）→ 结束（留下什么结果、下一镜从哪里接）。最终状态要能独立看懂：停止动画后仍不知道对象在哪里，就先改构图和信息层级。

再补四项：固定的是哪个参照，实际移动的是哪一层，什么时候留给观众读，下一镜接着解释什么。

## 指向 → 改变 → 读懂 → 交接

先让观众知道看哪里，再完成变化，然后留出理解时间，最后把注意交给下一处。标题进入用了两秒，不等于这两秒都是阅读时间。下面是第一次试作的起点，适用于旁白同时讲到这些字的情况，按字量、屏幕大小和观众调整；没有旁白帮忙、观众要自己读完的字，停留按约“字数 ÷ 4.5 + 1.5 秒”估：

| 内容 | 进入 | 完成后停留 |
|---|---|---|
| 短标签 | 0.2–0.5 秒 | 随讲解，至少能读完 |
| 六至十字的短语 | 0.3–0.6 秒 | 约 1.5–2.5 秒 |
| 两三项简单对照 | 0.6–1.2 秒 | 约 3–5 秒 |
| 第一次出现的流程图 | 分步建立 | 整体约 5–8 秒 |
| 重要结论后的停顿 | — | 约 0.4–1 秒 |

匀速适合扫描、路径和时间轴；起止缓和适合对象抵达；弹性和过冲显得活泼，但会干扰精确图表的读数。不要给所有层统一套一个缓动。

## 在 NoteToFilm 中怎样做

| 需要 | 做法 |
|---|---|
| 图片或视频上加框、箭头、标签、遮罩显露、路径绘出 | `ntf motion`：`reveal` 遮罩、`line`/`arrow` 的 `reveal_start`/`reveal_end`、带 `start`/`end`/`fade_in` 的 draw 图层；净画面和配字分 `picture`、`annotate` 两步 |
| 节点生长、原位替换、卡片让位、汇表、并行总览、镜头在图上移动 | 代码动画（`ntf web-render`），`motion.js` 的 `reveal`、`drawPath`、`typeOn`、`countUp`、`stagger`、`camera()`；写法见 compose 的代码动画手法库 |
| 只是静态标题或结论 | 合成清单的 `text_overlays` |

同一张图的几个状态尽量画在同一个页面或同一份 motion 清单里，下一镜从上一镜的末帧开始，避免每句重排版式。

## M01 遮罩显露｜让对象在需要时出现
- **用于**：资料展开、局部发现、图示逐步建立。观众先有一个参照，再发现新的部分。
- **过程**：完整图先隐藏一部分 → 遮罩揭开相关区域 → 区域完整可读，旧参照保留。
- **做法**：先显露对象或内容，不让整页空等；遮罩可以沿纸边、窗口或关系路径展开；被隐藏的部分在原图中真实存在。精确文字在独立图层里排。
- **误用**：文字只在运动瞬间出现；遮罩切断字、单位或关键连接。

## M02 路径绘出｜沿关系走
- **用于**：流程、路线、结构联系、随讲解延伸的曲线。线的起点、终点和方向都有意义。
- **过程**：起点出现 → 路径逐步连接 → 终点和关系标签出现并停留。
- **做法**：用路径长度控制显露，必要时加一个移动标记；画完留时间看整体。物料移动和消息传递用不同线型；数据曲线按真实数据画，不随意改形。
- **误用**：所有线同速乱长；用箭头把并行工作画成串行步骤；两种线混用，把“发出通知”读成“东西已经到了”。

## M03 局部强调｜让重点接管注意
- **用于**：复杂画面中的一处信息。强调只改变观看优先级，不新增事实。
- **过程**：整体先成立 → 非重点退弱，目标加框或划线 → 读完后恢复或交接。
- **做法**：降低周围对比度通常比同时加闪烁、描边、弹跳更干净；一次只设一个主强调。照片和文档里只加标注，不改写内容。
- **误用**：全屏都在高亮；删掉条件后得出比原文更绝对的结论。

## M04 保留与增补｜让两个事实同时成立
- **用于**：逐层建立判断条件，逐句补齐一组文字。新增不是替换，先前的事实留在画内。
- **过程**：“产品符合标准”成立 → “客户使用仍受阻”加入 → 两者同框，进入下一步选择。
- **做法**：稳定布局、独立标签、预留空位；新的一行接在旧行之后出现，顺序与解释顺序一致。内容多到挤压主体时，进入新论点就换构图，不无限堆字。
- **误用**：后一句出现时把前一句抹掉，观众看不到两者为何形成张力。

## M05 原位替换｜比较同一位置的前后状态
- **用于**：同一字段、同一环节的前后变化。前后内容属于同一个问题，才能借用位置记忆。
- **过程**：旧内容读清 → 同一位置换成新内容 → 对照意义保留。
- **做法**：固定容器和标题，旧内容先退弱再离开，新内容延后进场；需要同时比较时另留旧值。变形只用于视觉连续。
- **误用**：把另一口径的数字放进旧标题下，观众以为同一指标改善了。指标变了，标题一起换。

## M06 同位对照｜让差异成为唯一变化
- **用于**：标准与实际、之前与之后、两种方案。
- **过程**：共同基准建立 → A 状态 → B 状态或并列 → 差异标签保持。
- **做法**：固定尺度、基准和方向，只改变待比较的项。要同时比较就左右并列，要追踪变化就原位切换或擦除比较。缺少数据时只示意方向，不写数值。compose 的代码动画骨架就是同位对照示例。
- **误用**：大小不同被看成尺寸差；镜头角度的变化比真实差异更醒目。

## M07 归组与汇表｜让方法形成
- **用于**：散落的记录变成共同结构，事件变成分类，样件变成比较依据。
- **过程**：各自的记录和对象 → 共同字段对齐 → 汇成一张表或一套规则。
- **做法**：样件位置不动，先建立比较维度，再把记录连进对应行；表格出完给读的时间，不立刻翻页。没有真实数值时只放结构，不造评分。
- **误用**：几张纸飞来飞去却没有字段；空白表格配一句“体系建立”就结束。

## M08 并行展开｜多条工作同时存在
- **用于**：多团队协作、同时发生的行动。
- **过程**：第一条线启动 → 另两条加入 → 三条持续可见，当前项突出。
- **做法**：三条线共用一个阶段标签或同一条时间带；可以进入其中一条，其余缩成导航提示，再回到总览。“同时”需要材料依据，不确定时做成主题并列。没有工期数据就不画进度条。
- **误用**：一条做完才亮下一条，观众读成流程；用不同时间的素材制造“与此同时”。

## M09 总览进入局部｜同一对象带路
- **用于**：地图、流程、产品与具体场景之间的交接；资料从封面进入相关页；镜头沿关系从一个节点移到下一个。
- **过程**：总览里突出一项 → 该项接管画面 → 场景或细节展开，身份标记仍保留 → 需要时回到同一个总览。
- **做法**：缩放、遮罩和匹配切都可以；短暂停住后干净切入往往比无缝形变更明确。资料展开只给必要上下文，停在真正要读的部分。沿关系移动视野时，给停留的对象清楚的辨认时间。
- **误用**：每次回总览都重新排版；放大的对象到下一镜完全变样。

## M10 前后景视差｜形成观察距离
- **用于**：静态资料和插画的有限空间感，与 C12 配合。它是观察效果，不代表图中的人或设备真的在动。
- **过程**：前后层清楚 → 视点小幅改变 → 主体稳定，空间被感到。
- **做法**：分层、补背景、保留阴影关系；主要任务是比较时，保持平面更好，准确文档不要加透视。
- **误用**：为了“动”把每个部件分开漂浮，装配关系被破坏。

## M11 文字编排｜句子也是对象
- **用于**：对比、提问、引述和观点推进。
- **过程**：先建立文字要指向的对象 → 关键短语进入 → 重点词被强调，或与新条件并置。
- **做法**：画面上的字、字幕、旁白是三份文本，各管各的（见 [旁白与画面文字](../script.md)）。短标题留下判断，标签对应对象，字幕跟随讲话；整句有稳定的阅读时间。
- **误用**：逐字飞入来不及读；同一句话在标题、字幕、旁白里出现三遍。

## M12 数据变化｜先口径，再趋势
- **用于**：真实数量、比例、趋势和条件对照。
- **过程**：标题、单位和范围建立 → 数据进入 → 完成状态停留，结论对应可见的数据。
- **做法**：坐标系先出，数据再长，最后只标一件事；柱子从 0 开始，非零起点要明显写出；不改变数据的时间顺序。画面规则见风格库的数据动态。
- **误用**：柱形弹跳过冲被看成真实数值；面积、轴距或透视夸大结果。

## M13 卡片堆叠与让位｜清单逐项累积
- **用于**：建立一组指标、理由或步骤，并保持前面的项可见。
- **过程**：第一张卡出现并读完 → 第二张进入、补齐文字，第一张小幅让位 → 第三张加入，整组仍在画内。
- **做法**：旧卡移动距离尽量小，保住位置记忆；每张卡只放一个要点；最后整组停留，让观众把几项放在一起看。
- **误用**：旧卡飞出画面，观众忘了前面讲过什么；卡片同时进场，没有先后。

## M14 节点生长与退出｜让隐藏的一层出现
- **用于**：先交代两个主体，再加入中间参与者；或表示某个环节退出、被替代。
- **过程**：两端节点成立 → 中间节点从小点长成带标签的节点，连线接上 → 需要时，旧节点变暗、半透明后离开，原处换成新节点和说明。
- **做法**：新节点只在解释它时出现，不让所有圆点持续缩放；退出只用于真实的退出或替代，结构本身保留。
- **误用**：用删除动作暗示本来仍存在的工序被取消。

## M15 压暗背景，叠入说明｜现场留着，重点交给信息
- **用于**：现场画面上叠加流程、程序或引文，同时让观众记得这件事发生在哪里。
- **过程**：现场画面清楚 → 背景压暗或降低对比 → 图标、文字依次进入 → 说明结束后背景恢复或切走。
- **做法**：压暗到文字清楚即可，场景仍可辨认；说明内容沿用片中的文字样式。`ntf motion` 可加一个铺满画面的深色 `rect` draw 图层，图层 `opacity` 设约 0.5、配 `fade_in`，说明文字放在上面的图层。
- **误用**：把场景完全抹黑，等于换了一页幻灯片；说明压在人物脸和手上。

## M16 划线强调与划改｜指出重点或纠正一个说法
- **用于**：下划线让重点更明确；删除线表示纠正或否定一个说法，随后出现新的概括。
- **过程**：短语读清 → 线从无到短再延长 → 强调停留；或删除线延伸后，新词在旁边出现。
- **做法**：划改前讲清否定的是什么。例如划掉“已到站”，要说清否定的是“把它当作可以取件的条件”，而不是包裹到站这件事。一次只划一处。
- **误用**：用删除线改掉仍然成立的事实；满屏都是下划线。

# 衔接方式卡：T01–T15

转场先回答“为什么到下一镜”：两镜之间是同一个动作、同一个对象、一次视线、一段时间，还是一次论点的延续。关系成立后再选方式；关系不成立，再复杂的特效也只能遮住接缝。

## 先按两镜的关系选

| 两镜的关系 | 先考虑 | 要保留什么 |
|---|---|---|
| 同一个动作的不同视点 | T02 动作匹配、T09 插入细节 | 动作阶段、方向、持物方式和速度 |
| 目光引向画外 | T03 视线 | 视线方向和对象所在空间 |
| 从实物进入说明 | T04 图形匹配、T05 共享对象 | 轮廓、位置、朝向与身份 |
| 同一个论点换了材料 | T15 文字桥接、T08 声音桥 | 论点仍在继续，材料归属清楚 |
| 跨过一段时间 | T13 省略、T10 叠化、明确的时间提示 | 新旧状态有区别，不伪装成实时连续 |
| 几项行动同时进行 | T14 交叉剪辑、M08 并行总览 | 同一时段有依据，几条线可辨认 |
| 一段结束，另一段开始 | T01 硬切、T11 淡黑、环境声交接 | 上一段的收束和新段落的第一项信息 |

**先试干净切换。** 内容、方向和声音已经接得上时，硬切往往足够。叠化不是更高级，它让两幅画面短暂重叠，可能让字、结构或状态混在一起。

**转场成对设计。** 把 A 的结尾和 B 的开头写进转场对，记下共享对象的位置、声音交接的时点和要衔接的动作。用 `ntf compare A.mp4@3.96 B.mp4@0 --overlay --output DIR` 叠合检查对象身份、动作阶段和空间方向。示例取 4 秒、25 fps 素材 A 的最后一帧和素材 B 的第一帧。换用其他素材时，按实际采用范围填写两个取帧时点，B 有裁切时用其采用起点。

**一个切口一个主理由。** 一支片子选两三种衔接方式形成语法；每个剪点都加效果，转场就比内容显眼。

## 在 NoteToFilm 中怎样做

| 需要 | 做法 |
|---|---|
| 硬切 | 合成清单默认 `cut` |
| 均匀叠化 | 后一镜写 `"transition": {"type": "fade", "duration_seconds": 0.4}` |
| 颗粒溶解 | 后一镜的 `transition.type` 用 `dissolve`，画面以颗粒状逐点切换 |
| 推入、擦除 | `slideleft`/`slideright`、`wipeleft`/`wiperight`；用场景里的形状做遮罩要用代码动画 |
| 一段旁白跨两个画面（声音延续、插入镜头、文字桥接） | 同一镜写多条 `visuals`，旁白和 `text_overlays` 挂在这一镜 |
| 下一场声音先到 | 同一镜里先放 A 的画面、再放 B，旁白从镜头开始就是 B 的；或把 B 的环境声提前铺进底声 |
| 同一动作接续 | 视频尾帧接力：上一镜请求 `return_last_frame`，尾帧作下一镜 `image_to_video` 的首帧 |
| 从视频进入图解 | 代码动画第一帧把对象画在视频尾帧的位置，再展开解释 |
| 形状变形、穿越、色块淹没、遮罩擦除 | 代码动画，写法见 compose 的代码动画手法库第 5 节 |
| 淡黑 | 两镜之间插一个短的纯黑镜头，前后都用 `fade` |
| 连续环境声、音效对准剪点 | 预混成一条底声交给 `background_audio`，做法见 compose 的声音后期说明 |

## 借运动的整屏转场

想要冲击感时，转场多半来自镜头里本来就有的运动：一张纸飞过镜头盖住画面、人物一甩手镜头跟着甩到对面、东西从上一镜掉出画、下一镜砸在桌上、镜头往下穿过桌面进入图解。静图接静图时，只剩硬切、叠化和擦除可用，效果再花也像翻页；先让镜头里有人、有物在动，再设计转场。

在代码动画里做这类转场，逐帧看下面几处：

- **一次转场跨过剪点**：甩镜从上一镜结尾开始、在下一镜开头结束，两幅画面相邻着一起移动。上一镜已经把下一镜甩进来，下一镜就不要再从旁边甩一次，否则中间会闪回一帧上一镜。
- **不留空白帧**：向下穿过、向上穿出时，下一层紧贴着上一层的边缘进来；先移走上一层再画下一层，中间会露出底色，看起来像掉帧。
- **运动模糊用子帧**：快速整屏移动用 `ntf web-render --subframes 4` 得到真实的运动模糊。把同一幅图错开叠很多层，会显出一条条重影。开了子帧，页面要按帧时刻选镜头（见 compose 的 `motion-craft.md` 4.4），否则硬切处会混出一帧叠影。
- **遮挡物认得出、盖得住**：飞过镜头的东西要能认出来（纸上有红边和标题），在剪点那一刻盖住画面中央；掠过整幅约半秒，太快只像闪了一下。
- **一支片子两三种**：同一种整屏转场每隔几秒用一次就成了噪声；把它留给段落交接和情绪转折。

检查用 `ntf sheet FINAL --timeline TIMELINE --cuts --fps 8 --output DIR` 看每个剪点前后。要细看复杂转场的中段时，另开一次检查，用 `--start`、`--end` 指定区间，并提高抽帧频率。

## T01 硬切｜在关系清楚处直接换镜
- **用于**：同一件事的不同视点，或明确的段落推进。
- **过程**：A 完成当前的注意任务 → 切 → B 给出新的细节、反应或后果。
- **做法**：切在观众准备转移注意的地方：动作中、发现后、句中、句尾都可能成立。切点前后按正常速度看，不只看定帧。
- **误用**：每句必切；A 还没讲清就换，或者内容早已结束还在等旁白读完标题。

## T02 动作匹配｜动作继续
- **用于**：同一个动作跨景别或机位。连续感来自动作阶段和方向的对应。
- **过程**：中景双手托着物件开始放下 → 动作中切近景 → 接触、松手、结果稳定。
- **做法**：选动作最容易对应的一瞬切；两段素材要有可重叠的动作片段。生成视频用尾帧接力，剪点用 `ntf compare` 叠合核对位置。不重复完整动作。
- **误用**：前镜已经放下，后镜又重新举起；物件换手、旋转或变成另一种型号。

## T03 视线与主观｜把“看”变成观看线索
- **用于**：人物的注意推动故事。主观镜头接近角色所看；视线匹配只需关系成立。
- **过程**：角色看向某处 → 看到那里的对象 → 回到反应或后续行动。
- **做法**：生成 A 时写清视线方向，B 的构图符合“从那里看过去”；真实反应属于同一事件或交代清楚的上下文。人物视线也能让无人的对象成为下一镜中心。
- **误用**：拼接另一个时刻的表情，暗示他对某句话的反应；对象方向与目光相反。

## T04 图形匹配｜形式帮助交接
- **用于**：轮廓、位置、构图或运动方向相近的两个画面。
- **过程**：A 的圆形、接口或纸面成为重点 → 同位切换 → B 延续形状并展开新内容。
- **做法**：可以直接切，不必做变形；实物进入简图时保留朝向和基准。代码动画以前一镜末帧为起点画出对应形状。新对象的身份需要时及时说明。
- **误用**：为了好看硬接毫无关系的物件；让两个不同对象看起来像悄悄变形的同一个。

## T05 共享对象｜跨镜保留一个锚点
- **用于**：总览与局部、现场与解释、样件与表格之间。
- **过程**：A 中对象被选中 → 它在 B 同一位置延续 → B 改变环境或信息，身份仍可追踪。
- **做法**：只保留真正帮助理解的那一个对象，其他自然退出；缩放、遮罩、匹配切都可以，不必每次无缝形变。贯穿对象的识别特征写进美术设定表。
- **误用**：新镜换了图标却不交代；所有层都保留，画面越来越挤。

## T06 声音先行｜下一场的声音先到
- **用于**：从当前空间引向将要出现的人、场所或事件（J-cut）。
- **过程**：画面仍在 A → B 的环境声或讲话开始 → 画面切到 B。
- **做法**：提前量按语义和空间试，不固定成某个秒数；注意不要让观众以为是 A 中的人在说话。实现方式见上表。
- **误用**：两段关键讲话同时开始；把后期拟音伪装成原现场同期声。

## T07 声音延续｜上一场的声音继续
- **用于**：画面切到 B，A 的声音继续（L-cut），让讲述延伸到对应的细节，或保留一个场面的余波。
- **过程**：A 中说起一件事 → 画面切到相关动作或材料 → 这句话自然说完。
- **做法**：一段旁白挂在一镜里，用多条 `visuals` 依次接上相关画面；补充画面要和这句话直接相关。句子说完后可以短留动作声，不必立刻接下一句。
- **误用**：一段讲述下面连续铺任意的“行业素材”；画面改变了原话的范围。

## T08 声音桥｜空间与段落相连
- **用于**：环境、音乐、动作声或声音意象跨过画面切换，维持或转变观看关系。
- **过程**：A 的声音持续 → 画面变化 → 声音保留、交替，或由 B 接住。
- **做法**：同一场地的几个镜头用一条稳定的环境底声；换场地时逐渐换环境；重要转折可以故意断开形成对比。
- **误用**：每个切点都加“嗖”；用同一条背景声把不同地点伪装成连续现场。

## T09 插入与切离｜补细节或省略
- **用于**：插入主动作相关的细节；暂时离开主动作，给环境、反应或材料。可以帮助省略时间。
- **过程**：主场面建立 → 细节或相关视点进入 → 返回时状态合理推进。
- **做法**：省略的是无关等待，不是导致结果的关键动作；插入画面和主动作直接相关。
- **误用**：不断用手、键盘、机柜填空；删掉失败过程，让结果显得轻易。

## T10 叠化｜两幅画面短暂并存
- **用于**：柔和交接、时间流逝，或相关状态的联系。
- **过程**：A 完整 → A、B 短暂重叠 → B 完整可读。
- **做法**：叠化前先让非必要文字退出；两张图的明暗和布局要能叠；两个相同机位的前后对比直接切，差异往往更醒目。
- **误用**：把有连续动作的两镜一叠，出现幽灵手和幽灵物件；用模糊掩盖顺序错误。

## T11 淡入与淡黑｜明确收束与再开始
- **用于**：较大的时间或章节跳转、回忆与当下的分界，或空出一次思考。
- **过程**：上一段的意义完成 → 画面与声音收束 → 新段落建立新的时间和空间。
- **做法**：只在内容真的需要边界时用；声音可以先保留，也可以短暂降低密度。黑场不宜过长，观众会以为播放停了。
- **误用**：每个小节都黑场；把黑场当成情绪放大器。

## T12 遮挡、覆盖与运动转场｜沿真实边缘切换
- **用于**：物体经过镜头、纸面或照片从一侧覆盖进来、门框，或快速运动中交接画面。覆盖进入也适合交接叙述主体：从“发生了什么”转到“谁经历了这件事”。
- **过程**：A 中遮挡物接近 → 覆盖关键区域时切 → B 沿相容方向揭开；或人物照片从一侧部分覆盖，再占满主要区域。
- **做法**　先想好 B 从哪里揭开，让准确文字避开高速区。直线推入可用 `slideleft` 或 `slideright`，直线擦除可用 `wipeleft` 或 `wiperight`。用纸边、照片或形状遮挡时，在代码动画里沿它们的轮廓做覆盖。
- **误用**：遮挡物与内容无关；转场太长占掉解释时间；故意藏起手部变形。

## T13 跳切与时间省略｜保留重要过程
- **用于**：在相近构图中让时间跃过，压缩重复劳动，或明确展示阶段变化。
- **过程**：开始 → 略去重复或等待 → 更晚的状态，观众知道时间前进了。
- **做法**：重复动作选代表瞬间；必要时用“随后”“次日”交代。不同事件不能伪装成同一次。
- **误用**：剪掉需要理解的关键接触；无提示退回旧状态。

## T14 交叉剪辑｜把几条线组织起来
- **用于**：同时推进、等待与行动对照，也可以跨时空建立主题联系。两种时间含义要让观众分清。
- **过程**：A 线 → B 线 → 回到 A 的新进展 → 共同结果或主题汇合。
- **做法**：先建立每条线，再加快切换；每次返回都有变化，切换由动作、问题或声音触发。可以和 M08 的总览配合。“同时”需要依据，不确定时改为主题并列。
- **误用**：同一组静帧反复换却没有进展；把主题并列剪成一条虚假的因果链。

## T15 文字桥接｜一个论点跨过几种材料
- **用于**：同一个标题、问题或判断在几种不同素材上保持，表示论点还在继续，背景在补充不同细节。
- **过程**：标题出现在 A 上 → 背景换成 B、C，标题位置不动 → 论点讲完后标题退出。
- **做法**：一镜里写多条 `visuals`，标题用一条 `text_overlays` 覆盖整镜；或在代码动画里让文字层独立于背景。底下的素材都和这个论点直接相关。
- **误用**：标题长期挂着，其实下面已经在讲别的事；标题压住每张素材的重点。

# 按叙事目标选择镜头自由度

先写观众在这一段需要看懂的变化，再决定约束多少画面。用户已指定模式时按指定模式推进；以下是未指定时的选择依据。

| 当前需要 | 可采用的路线 | 固定什么，开放什么 |
|---|---|---|
| 探索故事感、现场过程与镜头节奏 | 纯文生视频 | 固定事件、因果和事实；开放构图、景别、运镜、动作细节和段内切镜 |
| 保持人物、设备或美术外观 | 通道支持的外观参考 | 固定必要外观；明确参考图是否约束空间和构图 |
| 从指定状态开始，或落到指定状态 | 首帧或首尾帧 | 固定时间端点，为中间动作留空间 |
| 解释精确结构、数字或逻辑关系 | 原始证据或后期图解 | 保持信息准确；用高亮、分步出现和局部运动引导阅读 |

不默认每幕先做参考图。参考图能提高外观一致性，也会把构图、主体位置和动作范围带入生成结果。固定机位、禁止推拉、保持原构图或精确动作轨迹，只在证据展示、匹配剪辑等具体需要下使用。稳定画面不等于人物和物件只能轻微晃动。

## 开放镜头任务模板

将以下内容写进制作说明，再转成当前路由可接受的提示词；这些是导演字段，不是新增 CLI 参数。

- **事件变化**：从什么处境出发，发生什么动作或选择，结束时什么改变了。
- **观众理解**：这一段增加了哪条信息或感受，为什么接在上一段后面。
- **事实与状态边界**：必须成立的对象、数量、工程关系、时间顺序；情境示意不能补成真实对话或事实。
- **总体审美**：材质、色调、空间和表演程度。
- **允许模型决定**：合理的机位、景别、动作细节、段内切镜和节奏。只列影响理解的硬约束。
- **声音与文字责任**：是否需要模型原声；旁白、字幕、关键词、技术标签由哪个环节制作。

## 从候选到完整版

先在已有费用授权内选择少量代表段验证方向。取得素材后看实际动作和可用时间范围，再确定剪点、分镜拆合及需要补拍的内容；不要把每次返回的整条视频直接塞入成片。有效镜头保留，其余按具体缺口调整。

检查故事连续性：对象和事件状态要与前后镜头一致，旁白时态对应画面进度，并行关系不能被画成先后依赖。相邻镜头通过同一物件、动作结果、视线或声音衔接，转场服务这一关系。

模型可探索视觉表达；选择成片素材时仍要检查物件变形、接触关系、身份、生成文字和过度表演。技术错误应裁掉、替换或补拍，不能只用旁白解释。纯静态证据可以保留静态；需要表现事件变化的段落应有观众可见的进展。

# 讲述结构与章节分镜

先用一句话写观众应带走的判断，再按材料选择理解顺序。三种基本叙事方式如下；具体片型的结构、开头和常用手法见 [片型配方](formats.md)，旁白写法见 [旁白与画面文字](script.md)。

| 叙事方式 | 推进主线 | 重点检查 |
|---|---|---|
| 案例故事 | 处境 → 阻碍 → 选择 → 行动 → 变化 | 选择为什么发生，行动怎样改变处境，结果有什么证据 |
| 原理解释 | 问题 → 对象与关系 → 机制或比较 → 结论 | 术语先有定位，比较维度一致，关键关系能在画面上看懂 |
| 观点论证 | 判断 → 证据与比较 → 推导 → 适用条件 | 证据能否支持判断，是否把相关性或个例扩成普遍结论 |

同一案例可以先叙事、局部解释，再回到行动和结果。制作路线通过 [设计选择图](design-map.md) 另行决定。

## 事实与叙述视角

证据、示意图和情境演绎在备稿和音画表里分别标明；画面上不加“示意”“情境演绎”之类的性质角标。材料中的可讲事实有编号时，在段落卡或音画表里注明每段旁白和屏幕文字依据哪几条；找不到依据的内容改写为演绎或示意，或者删去。画面里看不出的细节不写进旁白。成片后抽几句旁白对照联系表，检查画面与旁白所说是否矛盾。缺少的数字、对话、时间点和人物动作不能补成已发生事实；技术原图不足时只画已知关系，在备稿中记为示意，不造量测值或等级。第一人称故事要明确叙述者，普通旁白、演绎与真实采访在备稿中区分。

正式正文服务观众理解。写作框架、分析标签、引用说明和制作过程留在备稿层。管理案例的感染力可来自现场阻碍、决策、工作细节与产物，人物表演按实际叙事需要安排。

## 章节、段落、镜头、节拍

- **段落**：完成一次局面或认识的推进，可以跨几个地点，也可以在同一个地方。
- **镜头**：从一个视点连续观察。一个连续镜头里也可以先看人、再看桌面、最后揭示等待的人。
- **节拍**：观众注意或局面的一次变化：一个动作、一次发现、一次犹豫或沉默。三个节拍不一定要切三个镜头。
- **关键帧**：某一状态的记录，用来约定构图、对象位置和动作阶段；按顺序摆出来可以当粗剪，但它不等于最终分镜。

给 Agent 或制作者分任务时，写清是一个章节、一个连续镜头，还是由几个镜头完成的段落。

## 从章节到每一幕

先列每章的表达目标、起止变化、包含镜头和衔接。逐镜共同设计旁白与画面：旁白补充解释，画面表现事件或关系，屏幕文字保留需要准确阅读的结论、数字和标签。画面与旁白措辞可以不同，含义应一致。

每镜承担一个主要任务：展示对象、建立处境、发现异常、解释关系、比较差别或完成回扣。信息较多时拆成子镜头；同一业务段允许多条素材，开放生成的具体剪点可在选片后确定。相邻画面通过物件、视线、动作结果或因果衔接。

画面要求用动作句写：主体、动作、对象、结果，必要时补位置、景别和视线。“店员很忙，画面有压迫感”改成“中景，店员站在货架前，左手拿取件号，右手逐格查找；镜头末尾他放下手，转向画外的推车”。解释镜头同样写动作句：“流程图先显示到站扫描，扫描完成后出现通知分支；分类、上架仍在后方。”每个变化按开始、中间、结束三个状态写，最终状态能独立看懂。

状态不只是物件位置：人物知道了什么、风险是否还在、任务是否完成、资料是否从散页变成了共同比较，都属于状态。已经成立的状态在后面的镜头里继续成立，除非明确回溯。不必给所有事情补满中间过程，“办公室协调”之后直接接“备料台已经开始准备”可以成立；要连续展示的是帮助理解的关系。

审阅时并排比较缩小 JPEG：主体、景别、动作或解释关系是否有变化。相同画面只换标题或旁白、又没有连续叙事用途时，合并或重新设计。内部镜头 ID 保持固定，展示序号随当前数组顺序更新，阅读版、审阅页、总数与时间窗同步。

## 节奏：五条线排在同一条时间上

叙事决定什么时候发现问题，剪辑决定什么时候换视点，动作决定什么时候完成接触，文字决定什么时候读，声音决定什么时候停、重、轻。五条不必同时起止：镜头已经切到细节，旁白可以把上一句说完；字幕还在读时，背景只保持轻微动作；一段快速查找之后，给一个静止的对象让观众看清问题。

镜头时长先取“旁白实际时长、动作完成时长、必要阅读时长”中最长的一项作下限，再加少量识别与停留；三者能重叠的不机械相加，文字必须等动作结束才看得懂时，阅读时间另算。各镜时长不必相同，发现和转折处留停顿，重复信息压缩。停顿本身也在表达：观众可能正在比较、等待或重新理解；只有没有表达任务的空等才应压缩。

“一秒一切”“每三秒一个刺激”这类规则不作为标准。先看观众有没有跟上，期待和理解是否出现在正确的位置。

## 时间安排

写分镜前先粗估片长：中文旁白约 0.2 秒/字，加上镜头停留。超出目标时先删去次要事实或合并章节，再精简句子。用预计时长检查信息密度，可记录发音单位、语速与停顿；数字和缩写按实际读法估计。最终窗口由实际配音、动作和阅读需要共同决定，估计秒数不作为字幕时间戳。长过程可以拆镜，不以丢失事实或截断声音换取固定片长。

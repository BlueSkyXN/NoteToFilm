# 讲述结构与章节分镜

先用一句话写观众应带走的判断，再按材料选择理解顺序。下面是可调整的结构，不要求每个项目套同一组章节。

| 叙事方式 | 推进主线 | 重点检查 |
|---|---|---|
| 案例故事 | 处境 → 阻碍 → 选择 → 行动 → 变化 | 选择为什么发生，行动怎样改变处境，结果有什么证据 |
| 原理解释 | 问题 → 对象与关系 → 机制或比较 → 结论 | 术语先有定位，比较维度一致，关键关系能在画面上看懂 |
| 观点论证 | 判断 → 证据与比较 → 推导 → 适用条件 | 证据能否支持判断，是否把相关性或个例扩成普遍结论 |

同一案例可以先叙事、局部解释，再回到行动和结果。制作路线通过 [设计选择图](design-map.md) 另行决定。

## 事实与叙述视角

证据、示意图和情境演绎分别标明。缺少的数字、对话、时间点和人物动作不能补成已发生事实；技术原图不足时保留已知关系并说明示意，不造量测值或等级。第一人称故事要明确叙述者，普通旁白、演绎与真实采访在备稿中区分。

正式正文服务观众理解。写作框架、分析标签、引用说明和制作过程留在备稿层。管理案例的感染力可来自现场阻碍、决策、工作细节与产物，人物表演按实际叙事需要安排。

## 从章节到每一幕

先列每章的表达目标、起止变化、包含镜头和衔接。逐镜共同设计旁白与画面：旁白补充解释，画面表现事件或关系，屏幕文字保留需要准确阅读的结论、数字和标签。画面与旁白措辞可以不同，含义应一致。

每镜承担一个主要任务。信息较多时拆成子镜头；同一业务段允许多条素材，开放生成的具体剪点可在选片后确定。相邻画面通过物件、视线、动作结果或因果衔接。

审阅时并排比较缩小 JPEG：主体、景别、动作或解释关系是否有变化。相同画面只换标题或旁白、又没有连续叙事用途时，合并或重新设计。内部镜头 ID 保持固定，展示序号随当前数组顺序更新，阅读版、审阅页、总数与时间窗同步。

## 时间安排

用预计时长检查信息密度，可记录发音单位、语速与停顿；数字和缩写按实际读法估计。最终窗口由实际配音、动作和阅读需要共同决定，估计秒数不作为字幕时间戳。长过程可以拆镜，不以丢失事实或截断声音换取固定片长。

# 时间与音轨

静态镜头可按阅读需要和实际配音停留。视频按有效动作范围裁剪或组合；短于讲述时优先重组素材、拆镜或改稿。定格服务阅读与停顿，不默认用循环或长定格填满连续事件。

edge_tts：使用独立旁白。native：使用原视频音轨。mix：按明确方案混合两者。silent：明确无声。保留原始媒体，声音策略在合成时应用。

字幕按单镜实际边界和全片镜头偏移安排。阅读完整产物时注意关键字是否被裁掉、字幕是否遮挡重点、旁白是否被截断以及片段原声是否符合所选策略。

改顺序主要更新全片时间和衔接；新成片引用未变素材即可，首版可重新合成整片，不声称已经实现逐帧缓存系统。

准确字幕和图中配字在后期分别制作，视频生成提示说明是否需要原生声音及画面文字。环境声、现场原声和合成配乐分别标注来源；音轨非空不能证明原生音频或真实录音。

需要有故事感的片段应发生事件变化；缩放静态图、随机晃动和统一淡入淡出不能自动补足这项变化。相邻镜头可以接续动作、物件、视线、因果或声音。精确证据允许静态停留，给观众足够的阅读时间。

核对 `audio.start_seconds + 实测音频时长 <= 镜头窗口`，以及 `subtitles_offset_seconds + 最后一条字幕结束 <= 镜头窗口`。再检查叙述时态与事件状态，确保剪辑顺序符合材料中的先后关系。

现有合成清单支持 `trim_start`、`source_duration_seconds`、`speed` 和输出 `duration_seconds`，以及定时配字、字幕、音轨和明确的跨镜转场；字段见 [合成清单](manifest.md)。关键帧、遮罩和路径展开使用 [ntf motion](motion.md) 生成素材。变速后检查动作自然度与声音，转场后以实际时间表确认全片时长和字幕偏移。

出片后探测实际宽高、时长、帧率和音轨，完整解码一次；抽查开头、结尾、分镜衔接、字幕与关键动作，并在交付入口确认可播放。观看前的图片与抽帧使用缩小JPEG，保留高质量原件。

需要机器验收时为inspect提供期望尺寸、帧率、时长和音轨条件。audio-check分别报告样本音量dBFS、整体响度LUFS及分析所得真峰值；两者单位不同。指定验收失败时退出码2。正确解码与音量合格无法判断讲述是否准确，技术关系和字幕内容仍要人工审阅。

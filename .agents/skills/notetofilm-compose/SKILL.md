# 剪辑、合成与交付

1. 读 [本机入口](references/runtime.md)、[命令](references/commands.md)、[项目格式](references/project-format.md)。只有明确顺序的现成图音也可以建立项目后直接合成，不虚构旁白或分镜。
2. 导入实际媒体，读取尺寸、时长及音轨情况。按 [时间与声音](references/timeline.md) 为每镜确定实际窗口和音轨策略。
3. 从已选素材和采用时间范围形成清单，字段与示例见 [合成清单](references/manifest.md)。图片与视频可以混排，画面、准确文字和声音分别维护。镜头运动和转场按叙事关系选择，参考素材不自动作为成片素材。
   需要图层关键帧、遮罩或路径展开时，读 [参数化动效](references/motion.md)，用 `ntf motion` 取得并采用素材后再合成；视频变速与跨镜转场直接写在合成清单中。
4. 用 `ntf install-info` 查看字幕滤镜与可选 Pillow 的可用性；烧录或定时配字按合成清单选择渲染方式，编码前核对字体与文字内容。
5. 需要先了解实际合成安排时运行 `ntf compose PROJECT --manifest FILE --plan-only`；确定的清单执行同命令而不带该选项。
6. 通过工作流合成时执行对应 compose 动作。缺少素材时返回具体镜头与所需内容，由编排安排生成，不自行递归重做整条视频。
7. 按 [交付检查与命令](references/delivery.md) 核查技术规格和实际内容，必要时用 `ntf normalize` 双遍校准响度。保留原输出，携带对应时间表导出最终审阅页，用 `ntf serve` 播放和拖动检查。

视频短于讲述时必须有明确补画面、定格、追加片段或改稿方案，不默认截掉旁白。只输出计划、命令或静音占位文件不算完成成片。

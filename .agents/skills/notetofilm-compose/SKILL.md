# 剪辑、合成与交付

1. 读 [本机入口](references/runtime.md)、[命令](references/commands.md)、[项目格式](references/project-format.md)。只有明确顺序的现成图音也可以建立项目后直接合成，不虚构旁白或分镜。
2. 导入实际媒体，读取尺寸、时长及音轨情况。按 [时间与声音](references/timeline.md) 为每镜确定实际窗口和音轨策略。
3. 从已选素材和采用时间范围形成清单，字段与示例见 [合成清单](references/manifest.md)。图片与视频可以混排，画面、准确文字和声音分别维护。镜头运动和转场按叙事关系选择，参考素材不自动作为成片素材。
   需要图层关键帧、遮罩或路径展开时，读 [参数化动效](references/motion.md)，用 `ntf motion` 取得并采用素材后再合成；需要更自由的形变、连续对象运动或复杂排版时，读 [代码动画素材](references/code-animation.md)。分屏、画中画、宫格、图文排版、抽原声、取尾帧、局部去字、房间底噪等 `ntf` 未覆盖的加工，读 [本机工具箱](references/toolbox.md)，做出文件后导入。视频变速与跨镜转场直接写在合成清单中。
   环境底声、音效和音乐要按时间混在一起、并在旁白处让位时，读 [声音后期](references/sound-mix.md)，先预混成一条底声再作为 `background_audio`。无口播的宣传片、片头和方向小样没有现成曲子时，按同一份说明用 `ntf score` 写原创配乐和音效。
4. 用 `ntf install-info` 查看字幕滤镜与可选 Pillow 的可用性；烧录或定时配字按合成清单选择渲染方式，编码前核对字体与文字内容。
5. 自写动画和自混音也可以用显式清单出片。把渲好的画面、混音用 `ntf import` 登记并采用，在正式分镜记下相应镜头的可编辑源文件和时间范围，再交 `ntf compose PROJECT --manifest FILE` 编码并登记版本。需要预排时间时加 `--plan-only`。
6. 通过工作流合成时执行对应 compose 动作。缺少素材时返回具体镜头与所需内容，由编排安排生成，不自行递归重做整条视频。
7. 按 [交付检查与命令](references/delivery.md) 核查技术规格，并用联系表按时间看全片和剪点；联系表看不出画面停了多久，用 `ntf inspect --scan` 的冻结区间找出无意的空拍。必要时用 `ntf normalize` 双遍校准响度。交付前按其中的审片方法分别只看画面、只读旁白、连续看，写下最严重的三个问题；宿主能派子 Agent 时，可以请一个没参与制作的 Agent 独立审片。保留原输出，携带对应时间表导出最终审阅页，用 `ntf serve` 播放和拖动检查。

视频短于讲述时必须有明确补画面、定格、追加片段或改稿方案，不默认截掉旁白。只输出计划、命令或静音占位文件不算完成成片。
